### 1.4 类别特性（写入门面卡文案与 §3 挡弹语义）

- **法器（talisman）**：攻击体离手自主飞行/落点结算——范围/落点攻击，**无穿透概念**（范围内即等于穿透）；攻击体飞行路径与落点 **100% 挡子弹**（随机攻击天然铺场，确定性消弹，§3.2）。

### 2.2 法器·灵剑（W11_spirit_sword，新建）

**行为**：每拍向最近敌人掷出飞剑，直线高速刺击，**命中第一个敌人即没入（单体）**，伤害高。法器 100% 挡弹（飞行路径，§3.2）。

**实现载体**：`FlyingSwordWeapon extends WeaponBase`（新脚本）。发射真投射物（`projectile_pool.acquire()`，team=0），复用整条弹体管线（`_submit_hit` 四件套：暴击/乘区/ON_HIT 派发/附着），因此迸发/暴击/元素附着**免费获得**。ProjectileBase 新增飞行形态键（§2.3 同批）：

# spawn 参数新增（ProjectileBase._read_form_params 消费）：
"flight_sword": true          # 飞剑形态：视觉=飞剑贴图顺速度方向、拖刺击残影
"attach_elements": [int,...]  # 本发附着元素全集（§6.3；缺省 [] 旧弹零影响）

- 单体语义 = `pierce=1`（命中 1 敌即 `PIERCE_DEPLETED` 回收，projectile_base.gd:976-981 先例）——不与「法器无穿透概念」冲突：无穿透 = 永不穿过多目标，飞剑命中即消失即此语义。

### 2.3 法器·裂地斧（W12_ground_axe，新建）

**行为**：每拍向最近敌人头顶掷出巨斧，斧体**越过途中的敌人（飞行接触无伤害）**，抵达目标快照落点后**落地震荡**：半径内全体结算 + 裂地特效 + 100% 清弹。攻速慢、伤害超高——W7 慢速大范围生态位。

**实现载体**：`GroundAxeWeapon extends WeaponBase`（新脚本）。斧体 = 真投射物（projectile_pool），新增飞行形态键：

```gdscript
"flight_axe": true       # 幽灵飞行：_check_collision 对敌跳过（仅落点/寿命/出屏逻辑）
"target_point": Vector2  # 落点快照（发射时锁定最近敌位置；目标中途死亡不重锁）

func bullet_block_chance() -> float:
    # 挡弹概率：nullify 键（法器确定性）优先；否则 melee.block_chance 基线 + Σadd_block 池
    if data == null or data.form != GameConst.WeaponForm.MELEE:

    if bool(data.melee.get("nullify", false)):
        return 1.0
    var base := float(data.melee.get("block_chance", 0.0))
    var bonus := 0.0
    if trait_stack != null:

    return clampf(base + bonus, 0.0, 1.0)
```

## 5. 回旋刀（需求 9）

### 5.1 末端分裂语义校准

现状（侦察三路 + 核对员修正，行号已校准）：回旋弹回收点 = **返航到手 28px**（projectile_base.gd:574-577 `_recycle(FORCED)`），分裂（唯一生产者 EF_FRACTAL，ON_EXPIRE 写 split_request；引擎唯一消费点 `_recycle` 内 projectile_base.gd:1245-1249）因此恒发生在玩家身边 =「从角色分裂」。

**改法（ON_EXPIRE 整体前移 = 搬迁而非双发，不动 R241 锁）**：ProjectileBase 新字段 `_boom_expire_fired := false`；`_boom_step` 的**两个翻相分支**（甩满 `distance_to(_boom_origin) >= _boom_range` 与速度地板 60，projectile_base.gd:558-567 实读）翻相前置：

```gdscript
if not _boom_expire_fired:
    _boom_expire_fired = true
    var tctx := _dispatch_event(GameConst.TraitEvent.ON_EXPIRE)   # 全部 ON_EXPIRE 词条在此触发
    if tctx != null and not tctx.split_request.is_empty():
        var req: Dictionary = tctx.split_request
        request_split(int(req.get("count", 0)), float(req.get("spread_deg", 0.0)),
            float(req.get("inherit_ratio", 0.0)), bool(req.get("echo", false)))
```

`_recycle` 的 ON_EXPIRE 派发 + split 消费整段加守卫 `if not _boom_expire_fired:`——翻相过的回旋弹**不再二次派发**。

**★ 双发冲突修正（评审实查采纳）**：初稿「ON_EXPIRE 双派发无副作用」论断**为假**——`trait_effect_mech.gd:27-31` 实读（grep 定标）：MEC_KILL_BLAST「死亡新星」经 ON_EXPIRE 臂（:20-21）进 `_maybe_kill_blast`（:24-47），guard 仅有 `killed_target`（:30-31），:45-46 **直接副作用** `weapon.settle_aoe(last_hit_pos, radius, atk, true)` + `emit_kill_blast`；`MEC_KILL_BLAST.tres` 实读 `event_hooks=[5]`、params 仅 `requires_projectile: true` 无 required_forms → W10（form 0）可挂。若双派发，FRACTAL+KILL_BLAST 双挂的回旋刃会在甩满点与回手各炸一次 = 同一次击杀双倍新星。搬迁方案下全事件只发一次：
- **EF_FRACTAL**（分裂）：在甩满翻相点触发 = 需求 9 的末端语义 ✓。
- **MEC_KILL_BLAST**（死亡新星）：时点从「回手」提前到「甩程末端」，**爆炸位不变**（`_maybe_kill_blast` 结算位 = `p_ctx.projectile.last_hit_pos`，trait_effect_mech.gd:45 实读——击杀位与派发时点无关）；语义自洽 = 「甩程末端收束全部消亡效果」；无 `killed_target` 记录时 guard 原样不炸。
- 寿命兜底路径（翻相前 EXPIRED，`_boom_expire_fired=false`）走原 `_recycle` 派发，行为不变；非回旋弹零波及（flag 恒 false）。

### 6.1 裁定：触发侧「全元素并发」，染色侧「混色」
