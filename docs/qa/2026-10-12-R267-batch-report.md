## ② 反馈 B「发棕」——视觉定谳与实现

### 2.1 棕根因定谳（五点链，设计 §2.1，探针 r267_probe_w9_brown 生产函数直驱）

1. 染色入口无身份色保护：orbit_weapon.gd:535-555 不传 tint 键 → 元素池含任一非 KIN 元素时整刀主填充 = `blend_element_color()`（arc_slash.gd:152-164/:565-588），元素卡随局内升级累积 =「后期」第一层；
2. 混色数学落暖色相：weapon_base.gd:138-178 HSV 圆周均值+饱和取成员最大——FIR `#ef7938`/GEO `#fab632`/DEN `#a5c83b` 全是暖黄橙区；
3. saber 渐变把暖色变棕：arc_slash.gd:706-714 刀背 `darkened(0.45)/(0.30)` 只压明度不动色相/饱和——暖相+高饱和+低明度=棕；
4. 「后期」第二层 = L5 质变再加深 `T2_TINT_DARKEN=0.18` + 前导双残影同用；
5. 化身层同源（weapon_orbit_avatars.gd:153-154）。

数值实证：[FIR] 单元素即发棕（L5 填充 `#c4632e`，8 档 3 棕+2 暗橙）；五组暖池全棕（2-5/8 档）；冷色池 0/8 棕。

### 2.2 实现（设计 §2.2-2.5，一套生成器双形态）

- **棕修手法 = 明度策略反转**：弃「刀背压暗」改「外壳半透（α0.22）+ 亮核提亮（α0.92）+ 白色刃缘 + 内折射亮线」，生成器内部 `sat = maxf(c.s, 0.55)` 饱和下限钳制；`blend_element_color()` 全局单源语义零改动。
- 新建 `scripts/combat/weapon/melee/crystal_blade_factory.gd`：烘焙形态（W10/W11/W12 弹体+图标）+ 即时形态（W8/W9/W13 刀体顶点色）；静态缓存（键含 quality 防遮蔽）、零 rng、降档矩阵 [0,2,4]（档 2 五层/档 1 三层/档 0 单层+刃缘）。
- **KIN/身份豁免分支**：W13 黑金、W11 银蓝、W12 岩钢、W10 金、W9 青绿、W8 蓝身全部不进水晶配方，输出与基线逐位一致（a′ 断言；W13 `_t2_fill` 暗黑契约不破）。
- 六站点接线：W9/W13/W8 刀体 arc_slash.gd、W8 环刀 orbit_field.gd、W13 orbit_weapon.gd、W11 flying_sword_weapon.gd、W12 ground_axe_weapon.gd、W10+图标臂+委托表 texture_factory.gd；化身 0 行（modulate 已接）。
