## 2. vc27 真机验收读法 ★交付物二

**采日志**：设置 → 记录日志 开（默认开）；打完一局在主菜单导出（文件名带版本 vc27）。1Hz 采样 × 环形 N 行（日志长度档，默认 240）。

### 2.1 主判据（方案书 §2.3）

- **火段（火N）< 30ms**（PLAYING 行；刀12 生效时 ≤20ms 为子判据）；
- 卡开（开N）< 30ms 目标 <15ms；
- 弹段单刀降幅：**弹段ms × 1000 ÷ 结N = 每命中 µs**，对 vc26 同载荷基线单刀 ≥15% / 刀组 ≥40%。

### 2.2 波动带读法（用户验收口径 10%/30%）

- **target（调速器目标帧率）= min(帧率上限设置, 120, 屏幕刷新率)**——收口修轮帽语义（§3-6）：「帧率上限」是帽不是保底，60Hz 面板 + 上限120 时 target=60，**达不到上限不再被当掉帧**。
- **帧率优先（允许波动 ≤10%）**：PLAYING 段 fps 分布 **P5 ≥ 0.90 × target**（深谷不破 -10%），P50 ≥ 0.95 × target 视为达标；调速器档（调N）应稳定 3，变N 基本不涨。
- **特效优先（允许波动 ≤30%）**：P5 ≥ 0.70 × target；调速器可降至 2（地板 2，特效帽最多收到中档）。
- fps 是 Engine 平滑值，与逐帧清零的段探针**窗口错位**，两者不可直接互除对账（日志头口径声明同句）。

### 2.3 行尾新符号（R220 新增，日志头已带同款声明——收口修轮 §3-7）

| 符号 | 含义 | 判读 |
|---|---|---|
| `模N` | 实际模拟率 = 物理帧差分×1000÷采样墙钟窗 | PLAYING 连续行 ≈ min(fps,60)±2；**跨窗行带 `*`（选卡/暂停退出后首采）剔除不读** |
| `结N` | 本秒伤害结算数差分 | 定标口：每命中 µs = 弹段ms×1000÷结N；结N≈0 而弹段高 = 空转弹（远处敌弹），非命中链成本 |
| `自N` | 自导池在场数 | **弹N 不含自导**（0.2.1 口径纠正）——读弹幕总量时 弹N+自N |
| `调N` | 调速器档 1低/2中/3高 | mobile 上与敌特效帽联动；桌面恒显示不联动特效 |
| `变N` | 真采样驱动的累计档变数（>0 才出现） | 帧率优先真机若 变N 持续走高且 调N 钉 1：先核对 target 是否高于设备可达（帧率上限设置/刷新率），修轮后一般不该再发生 |

### 2.4 辅助计数口（DebugStats 通用通道）

`quota_deferred`（配额顺延）/ `quota_dropped`（队列帽丢弃——应为 0 或个位）/ `mirror_budget_skipped`（镜预算咬合——帧率优先下可非 0）/ `trait_pool_discarded`（刀5 池弃件——挂卡/质变后的首批弹出现属正常，稳态应归零）。
