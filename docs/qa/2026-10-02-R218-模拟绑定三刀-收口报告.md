# R218 收口报告：模拟绑定三刀（追赶帽1/分组N+他键/跳键）（2026-10-02）

## 0. 背景：vc25 定案（方向性转折）

R217 断批根修部分见效（fps 下限 13→20、部分满载段 47-59），但满载深谷主体仍在。vc25 日志给出**方向性定案**（tracker 二j）：

1. **渲染不是绑定约束**：同 dc 下选卡暂停态（0:24 dc769）fps120 vs 模拟态（1:02 dc787）fps11——GPU 画 769 dc 能 120fps。深谷=每帧模拟成本：已捕获逻辑 14-34ms × 追赶帽2 + 引擎侧 余15-56ms。
2. **螺旋在敌<80 仍续**（0:26 敌59 fps18）——追赶帽 2 在 fps<60 时每渲染帧双倍逻辑成本，维持低 fps。
3. **断N 高计**：断49-85 含狂暴常驻 0.18 红全体（同值并不真断批）——需真分组口径。
4. **UI/跳字尖峰 53-200ms 与 跳N≈40 满帽强相关**。

## 1. 改动清单（三刀）

### 刀B：mobile 追赶帽 2→1（meta_manager.gd `_apply_fps_cap`）

- **fps ≥ 60 时帽 1 是无操作**：60Hz 物理、每渲染帧至多欠 1 步，120Hz 渲染有 2 倍步进余量自然追平——只在 fps<60 螺旋段生效。
- 螺旋段每渲染帧逻辑成本**即刻减半**（vc25：帽2 下 fps11×2 步=22Hz 模拟；帽1 渲染帧率翻倍以上、模拟率不降反升）。
- 不挂敌数门——敌<80 螺旋尾段（0:26 敌59 fps18）同样覆盖。
- R206 帽 2 定案的迭代翻案（当时 8→2 解决冻结；2→1 解决双倍烧）。

### 刀A：分组N + 他键（归因遥测）

- **分组N**（enemy.gd `sprite_modulate_key()` + game_loop.diag_counts 新键 `tint_groups`）：敌桶内 distinct (modulate|self_modulate|根α) 元组数 = **真合批分组上限**——断N 是「非白敌数」（高计），组N 才是断批上限。≤档组合数≈16 为 R217 设计达成；**组N 低而 dc 高 → 断批源在桶外**（下轮靶）。
- **他键**（game_loop `_physics_process` 头尾包裹）：他 = 物理帧全函数 − Σ十五段互斥和——段间空隙/编排/事件派发等**未捕获 GDScript** 归因（vc25 引擎侧 余15-56ms 先切出我方部分；余=纯引擎侧）。

### 刀C：跳键 + 满载跳字帽

- **跳键**（`_tick_ui` 拆分）：popup_manager.tick 独立计时（含 R212 排版批）→ `popup`「跳」键；UI 键=HUD/Boss条/震屏——vc25 UI 尖峰 53-200ms 的归因粒度。
- **满载跳字帽 40→24**（popup_manager.max_active_for）：mobile 高档门内 `24 if fullload_dim() else 40`；只作用新起跳字（在场超帽自然衰减）；层1 滚字合并不受影响。
- DIAG_STAGE_ORDER 十三段→**十五段**（跳插 fx 后 ui 前、他殿后）；余值求和跳过 移/火/跳 三子集键。

## 5. vc26 真机验证清单

1. **满载 fps 地板抬升**（刀B 直接验收）：帽1 下深谷段（敌95-120）期望脱离 11-25 区间（帽2 同段 vc25 读数 19-40 为基线；>40 有效、60+ 达标半程）；模拟率读法——同段 fps 即模拟 Hz（帽1 单步）。
2. **组N vs dc 对读**（刀A 核心读数）：满载组N 期望 ≤16（档组合上限）且与 dc 相关性弱化；**组N 低而 dc 仍高 → 断批源在桶外**（弹幕桶内变体/皇冠卫星挂件——下轮靶立案）。
3. **他键读数**：深谷段 他N 每帧毫秒（未捕获 GDScript）vs 余（纯引擎侧）配比——他大→下轮刀我方未捕获段（spawner/bucket 维护/事件派发）；余大→引擎侧（物理/渲染提交），考虑降物理频率或减 canvas 对象。
4. **跳键 vs UI 键**：尖峰归 跳（popup 排版）还是 UI（HUD）——跳大则下轮跳字位图化/合批，UI 大则 HUD 刷新节流。
5. **跳字帽观感**：满载期同屏跳字 24 上限是否可感（层1 合并仍在）——可否决。
6. **帽 1 慢动作感知（⚠ 口径）**：中频段 40-59fps 游戏速度按比例略慢（模N 读数<60 即慢动作，50fps≈0.83×）；深谷段这是「更流畅的慢动作」替代「实时卡顿」——如果觉得慢动作不可接受指出来，回退方案=帽分段（<40fps 用 1、40-59 用 2）。
7. **模N vs fps 对读**：模N≈min(fps,60)；模N 恒 60 而 fps 低=渲染瓶颈；模N<60=模拟减载生效中。
8. 保持干净复验：磁0、碎0、开局、回菜单 fps。

## 6. 遗留

- 若 vc26 显示 组N ≤16 而 dc 仍 600+：断批源在桶外（弹幕桶内变体/皇冠卫星挂件/粒子）——下轮靶；
