## 1. 改动清单（三刀）

### 刀A：敌侧染色确定性重算 + 档位量化（enemy.gd）

核心原则：**同状态组合的敌同帧同色 → 同桶同批**。断批分组从 ~N（逐敌独特值）压到 ≤ 档组合数。

- 新 `_apply_body_tint(p_game_delta)` = self_modulate **唯一写点**，每帧从 WHITE 起点确定性重算（不再 lerp 收敛链，无路径依赖）：
  - 燃烧呼吸量化 2 档：`sin(_anim_t*6.2) ≥ 0 → 0.46 / < 0 → 0.30`（原 `0.38+0.1*sin` 连续）；
  - 感电方波 2 值：0.14 / 0（原 `maxf(sin,0)*0.14` 连续）；
  - 吟唱 2 档：进度 ≥0.5 → 0.85 / <0.5 → 0.45；
  - 闪紫前摇 2 档：前摇进度 ≥0.5 → 0.8 / <0.5 → 0.4；
  - 狂暴两档绝对值：入场窗（_red_tint_left>0）→ 0.45 / 常驻 → 0.18（原每帧 lerp 收敛 = 常驻断批元凶之一；倒计时随本函数每帧递减一次，30Hz 转发传 0.0 不双扣）；
  - 冻结 0.88 / 寒滞 0.55 固定系数不变（本就确定）。
- 闪白满载分支量化 2 档：`p_amount ≥ 0.5 → WHITE×2.4 / → WHITE×1.5`（原 `×(1+2p)` 连续）。非满载 shader 路径不动。
- 入场渐显量化 4 档：`alpha = round(a×3)/3`。
- `_tick_status_tint` 保留签名转发 `_apply_body_tint(0.0)`（30Hz 门内幂等——同帧重复调用同值）。
- 新 `is_batch_broken()`：modulate / self_modulate 任一非白 → 断批（遥测直读口）。

## 5. vc25 真机验证清单

1. **满载段 断N vs dc 对读**（核心）：满载敌 80-120 期 断N 应≈常态低位（仅闪白敌/入场敌瞬时计入），dc 期望从 500-1040 显著回落；若 dc 仍高而 断N 低 → 残余源在别处（弹幕/挂件，下一轮靶）。
2. **满载 fps 基线**：期望脱离 13-26 深谷向上抬升（>40 为有效信号，90+ 为达标）。
3. **移/火 拆键读数**：原「玩」键尖峰 115/117 归到 移 还是 火（火→武器调度四组下钻；移→增益/移动）。
4. **跳N vs 卡键/UI 键对读**：跳字在场数与 UI 键尖峰相关性（跳字 Label 为最后未处理的断批源）。
5. **视觉口径确认（可否决）**：闪白两档（1.5×/2.4×）、燃烧呼吸两档明暗（0.46/0.30）、感电 0.14 方波（评审#6：对白很淡，重点目检可辨性）、吟唱/闪紫两档、闪白窗末档跳变突跳感、狂暴绝对红、入场渐显四档、**满载档余烬光晕隐藏（修轮#1，「在烧」读感由本体呼吸独自承担）**——若读感劣化指名哪项，回滚该档改回连续（牺牲该敌批处理）。
6. 保持干净项复验：磁0、碎0、开局、回菜单 fps。
7. **余值口径变更提示**：修轮#2 后「余」读数会比 vc24 同负载下偏高 1-5ms——这是修正双计后的真实引擎侧占比，不是劣化。
