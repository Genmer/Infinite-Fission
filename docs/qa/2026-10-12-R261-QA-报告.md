## 缺陷清单

### QA-261-1【medium】预选跳页在「基签名变化」的 open 路径失效（首开/换难度重开）

- 复现步骤（自动化：`tests/qa_r261_probe_deep.gd` 补1/补2）：
  1. 新建 `BlessingPickUI`（或换难度重开：先 T1 池 open 过，再以 T2 池+记忆项 open）；
  2. `open(蓝池26项, 记忆项=池第8项(页2), 0)`。
- 期望（本批改动清单第 3 条原文）：「预选跳页：open 时记忆项在后续页直接跳所在页+选中在树」。
- 实际（`_qa_r261_probe_deep_run2.log`）：
  - 补1：`page=0 sel_btn=false pressed=false sel_id_empty=false` —— 停在页 1、无选中行、无按下态；
  - 补2（T1→T2 换档重开）：`page=0 sel_btn=false`。
- 根因（代码定位 `blessing_pick_ui.gd`）：`open()` 在 L97-99 完成跳页赋值 `_page = find/7` 后调用 `_rebuild_rows()`（L100）；`_rebuild_rows()` 的基签名分支（L148-151）在 `base_sig != _rows_sig` 时无条件 `_page = 0`，覆盖跳页；随后 `_row_by_id()` 只搜当前页 → 记忆项不在页 0 → 按下态设置被跳过。
- 影响面：真机最常见路径即中招——记忆跨会话持久（Meta 落盘），新会话首次出发的首开 `_rows_sig==""` 必变签名；换难度重开同理。记忆携带语义本身仍正确（`_selected_id` 已 armed，直接出发仍带记忆项），故定 medium 非 high。
- 覆盖缺口说明：主控用例「预选跳页：末页项 open 直跳」恰走了同签名重开路径（前序 open 已把签名置同），未覆盖签名变化路径——本缺陷由 QA 探针补测发现。

### QA-261-2【medium】翻页清选中态与 `_selected_id` 不一致（隐藏携带 + 重访丢高亮）

- 复现步骤（自动化：`tests/qa_r261_probe_deep.gd` d 段）：
  - 路径①：页1 选 A → 下一页 → 上一页（往返，未再选）；
  - 路径②：页2 选 B → 翻回页1 → 再翻到页2（重访选中所在页）。
- 期望：跨页单选语义自洽——视觉取消则逻辑也取消，或选中保持则高亮也保持（任务书 d 项：「选中态正确」）。
- 实际（`_qa_r261_probe_deep_run2.log`）：
  - 路径①：A 视觉已取消 ✓（任务口径过），但 `d-翻页往返（未再选）：_selected_id 仍 armed` —— 面板无任何选中显示，按「出发」却携带 A（隐藏携带）；
  - 路径②：`d-重访选中所在页：B 应保持选中态 FAIL b_pressed=false`（`_selected_id` 仍=B）—— 当前选中项重访所在页高亮丢失，玩家看不到自己选了什么。
- 根因：`_rebuild_rows()` 末尾「翻页后选中态全清」只对挂树行 `set_pressed_no_signal(false)`（不发 toggled 信号），`_selected_id` 从不清——三态不一致的单一根因。
- 影响面：不丢数据（逻辑选中正确、出发携带正确），但选中反馈丢失/隐藏携带可误导出发决策，定 medium。

### QA-261-3【low】筛选跨档保留遇空类：空列表且激活签隐藏（无可视激活态）

- 复现步骤（自动化：`tests/qa_r261_probe_deep.gd` b补段）：困难局（T2）点「乘算」签 → 关面板 → 切普通难度（T1，乘算 0 项）开局弹面板。
- 期望：保留筛选的意图下，激活筛选应可见可理解（或回退「全部」）。
- 实际：`乘算签隐藏 + 列表 0 行 + 翻页静默`——玩家视角「没有祝福可选」且无任何页签高亮解释原因；点「全部」一击自愈（自愈路径已断言绿）。
- 定级 low：可达路径窄（跨难度+特定类组合）、一击可恢复、不崩溃不阻塞。
