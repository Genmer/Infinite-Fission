## 缺陷清单

### DEF-1（medium，已修复）选关/每日出发钮直关面板不清挂起标志 → 回大厅双泵永久停摆

- **位置**：`scripts/ui/menu_screen.gd` `_on_map_pick()`（原 :763-769）与 `_on_daily_start()`（原 :2222-2226）——`_panel_root.visible = false` 但不 `_lobby_detail_open = false`/`_panel_kind = ""`
- **复现步骤**（修前，tests/qa_r260_qa_pump_cases.gd D 组，隔离探针断开 start_map_requested 后直调）：
  1. `menu._open_map_select()` → `menu._on_map_pick(MapTable.FIRST_MAP_ID)`
  2. 观测：`_panel_root.visible == false` 但 `menu.card_desc_pump_paused() == true`
  3. `menu._on_state_changed(PLAYING)` → `menu._on_state_changed(MENU)`（模拟打完一局回大厅）→ 双泵仍挂起（`_panel_kind=="map"` 残留）
- **期望**：面板已关（且已离场回大厅）→ R260 设计「回大厅=双泵恢复」应成立
- **实际**（run2 日志）：`D1a FAIL panel_shown=true panel_hidden=true 泵仍挂起=true（_lobby_detail_open 残留）`；`D1b FAIL card=true codex=true（残留 _panel_kind=map）`；`D2 FAIL`（每日同型）
- **影响**：玩家最主流流程（出发→打完→回大厅）后 CardDesc 预热/图鉴预建双泵静默停摆，R220/R254/R259 的首开提速失效；唯一自愈路径=再手动开任一面板再关（专项① D1c 实证）
- **严重级别**：medium（主流程可走、可绕过，但性能特性在主流路径静默失效；主控评审标 HIGH-1 从其门禁口径）

### GAP-1（medium，已修复）设置屏（大厅入口）开着时双泵照跑

- **位置**：修前 `menu_screen._on_lobby_pressed("settings")` 早退不置位 + game_loop 设置接线无 `set_blessing_modal` 同款调点
- **取证**：SettingsPanel = CanvasLayer layer 10、全屏 DIM、open() 即 `squash_pop`（settings_panel.gd:45/84-85），菜单在其下保持可见且 `_process` 照跑——与 R260 挂起动因（Q 弹动画帧叠加泵预算）完全同型
- **复现**（修前，专项① E1）：`menu._on_lobby_pressed("settings")` → `settings_panel.is_open()==true && menu.card_desc_pump_paused()==false`
- **修复**：`_settings_modal` 标志 + `set_settings_modal()` + `_on_settings_open_defer`/`_on_settings_closed_persist` 双向接线（评审 MED-1）
