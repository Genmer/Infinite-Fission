## 二、复现构成（如实声明——与真机的已知差异）

- **场景**：`start_run` 后恒 PLAYING（R223 ⑥ 战斗门要求；QA 插桩实证 2 run×3 情景×1800 帧 0 违规帧）。驻场 120 顶 MAX_ONSCREEN 闸，但 **wave_director 硬帽叠波仍推进（QA D1：wave 1→4，自然怪经死亡缺口漏入 ≈总击杀 0.5-1%——量级实测不入门，击杀口径同量级低估）**。
- **敌构成**：grove 波表 index==16 条目按 count 展开（E1_grunt×26/E10_woodbird×6/E2_runner×7/E3_bastion×3），死亡即随机位补位（≤8/帧 同款节流）；手动 spawn 绕过出生管线——跳过 R28/R72 出生乘区（普通 ×1.2 基线）与远程敌 projectile_pool 注入（**E3_bastion 等不开火=真机敌方弹负载不在复现口径**，QA D4 披露）。
- **构筑近似**（真机构筑未知，按日志指纹定标）：W2 加特林 L5 + 五词条满叠（AFF_PIERCE×3/AFF_MULTI×2/MEC_BOUNCE×3/MEC_KILL_BLAST×2/MEC_FRACTAL×2）；**棱镜五镜不装**（满配实测弹 p50 370-391 超带上沿，砍镜落带；真机镜5 为 R219 推断指纹非日志直读）；自导不装（日志自N≈0）。
- **定标旋钮**：敌血 ×0.3（击杀率×敌群密度均衡点；实证 ×0.05 杀太快密度塌→新星当量反降）；玩家风筝轨迹（慢速小环——站桩实测敌贴脸弹出膛即死=非真机形态）。
- **调速器**：冻结采样 + tier_override=2 + 帧率优先（=vc30 深载稳态档）。
- **情景矩阵**：S0 预算关（-2 无刀基线）/ S1 模拟真机（-3 tier2@60Hz 未饱和=真机快速段形态）/ S2 强制帽 48（吞吐 2880/s≈真机 tier2@26fps 的 2496/s——饱和态复现）。
- **不可复现项**：渲染面（dc/o）headless 不渲染；桌面 popup 首排版立即 vs 真机 mobile 限批方向相反（popup 段判读注意）；绝对 ms 桌面≠真机（见 §四系数）。

**读数一（修订）：刀R 效力的证据链不在桌面 ms 轴**——三样本弹段均值变化方向不稳（−45%/+26%/−11%），桌面单轮 ms 差不能作为刀效结论；刀R 的效力证据=①真机 vc30 尖峰弹 26-72ms vs vc29 27-123（真机轴）+②S2 饱和轴三读数跨运行稳定贴帽（结 44.6-44.8/顺 35-37/弃 4.9-5.8）。后续性能轮基准用法=**同日成对 BEFORE/AFTER 各 ≥3 轮取中位数**，单轮差一律不得立论。

**读数二（降级为假设）：「帽内结算占弹段大头」未分离测量**——~300-500µs/结算口径=弹段÷结算数的**上界**（混弹 tick+级联突发；对刀不敏感即证）。resolve 瘦身 ≤100µs 目标在分离测量前是**假设**；下一轮首动作=弹段双组成分离测量（settle-only 计时钩或 tick-only 空载对照），据实测再立验收门与排序。**S2「同需求」净值口径**：S2 提交读数 5094/s 含顺延冲刷复记（顺 35/步×60≈2100/s）——净需求 ≈3000/s ≈ S0 水平，故 S0↔S2 为同净需求对照（但见读一：ms 轴不稳，此对照只支撑形态不支撑百分比）。

**读数三：绝对系数修正（×0.5-2）**——R219 微基准 ×5-10 带对本复合负载不适用：桌面 S2 弹段 14-24ms vs 真机弹段采样 10-46ms，原始交叉比 0.42-3.3、取整带 ×0.5-2（**R224 修正，待 vc31 真机读数精定；探针头注/运行时输出/JSON meta 已同步此带，勿再引旧带**）。

**读数四：渲染面缺口（本基准不可测，真机证据链）**——vc30 收尾段（敌≤6、dc 260-400）fps 78-102 恒不达 120 = 本机渲染+引擎地板 ≈9-12ms 已贴 90-120 帧预算；深载 dc 834-994/o 2511-2771 只会更差。**90-120 硬指标必须双主线**：仿真侧 + 渲染侧（dc/o 减半：跳字位图化/满载敌视觉再降档/碎片精灵并批——R217/R216 方法论可复用）。

## 五、下一主线排序（定量依据=本基准+vc30；**Ⓐ 分离测量为第 0 步**）

0. **Ⓐ 弹段双组成分离测量**（settle-only vs tick-only）——决定 ⒈与⒉之间的资源分配，先测后刀。
1. **渲染主线首刀**（真机地板主单项）：满载 dc 900+ → 目标 ≤450。候选按 ROI：满载期跳字位图化（popup Label→缓存位图，dc −24 起）、敌满载视觉降档加深、碎片/弹出物并批复查。
2. **resolve 瘦身刀 或 弹 tick/需求侧刀**（按 Ⓐ 实测重排：若 tick 份额过半，resolve 瘦身摸不到大头——需求侧候选〔弹N 驻场帽/每敌每帧 rollup〕升位；R224 定向原列此候选，基准数据尚不足以裁决，挂 Ⓐ 后）。
3. **尖峰开 118ms 削峰**（vc30 反向恶化项）：开窗级联分解（卡面创建/量测/点阵分帧深化）。
4. 观察项：弃N 真机深谷 300-936/s（伤害卸载披露持续）→ 若渲染+仿真刀落位后 fps 上行，弃N 应自然回落（吞吐帽×fps 升）。
5. 需求强度补齐：夹具原生需求仅达深段 50-65%（M3）——若后续轮需要深段强度复现（4600-5700/s），升构筑近似档（更多武器源/词条堆叠）再校准。
