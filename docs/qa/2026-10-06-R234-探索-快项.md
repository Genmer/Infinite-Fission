## 1. 敌 Area2D→SpaceGrid 迁移（backlog #7）——**不做完整迁移；mask 收窄 2 行搭车真机验证**

**Area2D 实际用途（代码查证）**：enemy.gd:2-5 头注——弹-敌命中已走 SpaceGrid（Q-15）、敌间分离走网格 10Hz（E-10），`_hit_area` 仅剩「玩家接触伤害例外通道」：`_on_contact_area/_on_contact_area_left` 维护 `_contact_player` 旗（enemy.gd:511-541），tick 读旗结算（enemy.gd:766-767）。玩家本体 extends Area2D（player.gd:11，r=16），**玩家侧零监测消费者**（全仓 grep `area_entered` 仅 enemy.gd 一处）。

**成本实测（两路）**：
- 主探针 A/B/C 引擎臂（121 Area2D 真实战斗负载，读 `Performance.TIME_PHYSICS_PROCESS`）：A 现状 p50=34.09ms / B 敌mask收窄 p50=44.38ms / C 监测全关 p50=38.04ms / A2 复验 p50=38.46ms——**臂间漂移（10ms 级）≫ 臂效应，三态无序**，Area2D 监测成本淹没在 30ms 弹段噪声之下。
- 纯物理微基准（剥离 GameLoop，121 个 Area2D 挤团微移，n=400/态）：**def p50=0.941ms / mask p50=0.932ms / off p50=1.065ms**——121 挤团 Area2D 的全部物理成本（broadphase+transform 同步+pair）≈0.94ms/步（桌面，含空回调底噪），且 mask 收窄与全关 **p50 无差**。

**结论**：「vc37 余 36-42ms 未归因桶头号嫌疑=120 敌 Area2D」的假设**在桌面被证伪**（全成本 ≤1ms）。真机 ARM broadphase 或慢 2-5 倍（0.5-2ms 系数带内），仍非主头；余桶主体应重新归因到渲染（vc37/38 深载 dc 700-1000）与引擎 canvas 侧——建议 R234 用真机 dc/渲染轴再归因。附带发现：全仓零 `collision_layer/collision_mask` 配置（grep scripts+scenes 无一命中）——121 个 Area2D 以默认 layer=1/mask=1 **互相监测**，敌-敌 pair 检测纯浪费但量级已证可忽略。

**定案**：
- 完整迁移 SpaceGrid（1-1.5 人日）：**不做**——实测收益上限 ≤1ms/步，且 enemy.gd:506-510 已记录「tick 内直算圆距」变体曾被 blink_cases 走位出圈用例否决的语义前科，等价性风险不对等回报。
- 敌 `_hit_area.collision_mask=2` + 玩家 `collision_layer=3`（2 行）：**搭车 vc39 真机 A/B**（零成本零风险：`_on_contact_area` 只认 Player，mask 只动 pair 集不动信号过滤，语义逐位）。桌面已证无回归亦无收益；真机若有差即白捡，无差则关闭本项。

## 4. 自由挖掘——**做：跳弹臂快路径扩展（本轮第一大头）+双查询合并+关态快照短路**

### 4a. 弹段快路径扩展·跳弹臂（R231 刀D 顺延）——**做，组合主体**

**依据链**：D 臂弹段 30.09ms（73% 大头）；pfast 覆盖 p50 仅 47-61%（BOUNCE×3 构筑下 `bounces_left==0` 判据把全部跳弹弹排除在快路径外，projectile_base.gd:324-329）——即 130-200 发/步走慢路径全链（tick() :347-402）：`_apply_converge_steer` 守卫调用+`_check_edge_bounce` 四边计算+`_check_offscreen`+`_sync_visual` 全量+ON_TICK 闸。跳弹弹 95%+ 时间在中场直线飞（贴边瞬间才反弹），慢链几乎全 no-op。按 pfast 弹与慢弹成本差（~40-70µs/弹/步，GDScript 链长差）估省 **6-9ms/步（桌面口径）**。

**方案**：spawn 判据放宽 `bounces_left == 0` → 允许 `bounces_left > 0`（其余排除项 conv/LTG/boomerang/ON_TICK-armed/EF_SIZE/accel 不动）；`_tick_fast_player` 运动后加「贴边带预检」（与 `_check_edge_bounce` 同口径四边比较 `pos ≤ r / ≥ screen−r`，r 用 `_fast_radius`）：未贴边=跳过全部慢链（现状快路径继续）；**贴边=调 `_check_edge_bounce()` 本体，若发生反射补一次 `_sync_visual()`**（`_apply_bounce` 置 `_vis_variant=-1` 后需单帧刷新；ON_BOUNCE 派发/回廊镜像/计数全在 `_apply_bounce` 内自动照走）。反弹帧语义与慢路径逐位等价（预检回落先例=现有 `_check_collision` 回落，:489-490）。

**风险与对冲**：预检带与判定带口径必须同源（同读 `_fast_radius`；EF_SIZE 弹已被判据排除，半径生命周期不变成立）；QA 用固定种子 A/B 双跑（开关静态注入，R231 `PLAYER_BULLET_FAST_PATH` 同款回退口）对拍弹位序列/反弹计数/回收原因；电池 120 套件 FAILS:0 复跑。

**工作量**：1.25 人日（含 QA 对拍）。**预期**：弹段 30 → 21-24ms（桌面）；真机深载弹段 25-35ms → 16-26ms（×0.5-2 带内）。
