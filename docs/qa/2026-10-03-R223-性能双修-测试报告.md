## 缺陷清单

### QA-1（HIGH）预算顺延项冲刷缺 uid 复验：同帧击杀→池节点复活时幻影伤害落新敌人

- 复现步骤（tests/runner/test_qa_r223_probe.gd P2c2，headless 确定性）：
  1. `DamagePipeline.settle_budget_override = 1`（真机自动门 tier1/2 同分支）；
  2. `begin_frame(F)`：`resolve` 真结算一发（预算耗尽），再 `resolve` 敌 B 一发 → 顺延占位（`_pending_fifo=[B对]`，B 存活、超帽跨帧头存活）；`end_frame`；
  3. 模拟帧内后半（④/⑤ 击杀→`on_enemy_killed` 即池归还，⑥ 出怪段 ≤8/帧同帧复用）：`EnemyPool.release(B)`（节点身份不变，`_reset_state` 置 `dead=true`）；`pool.acquire()`（LIFO `pop_back` 取回同一节点）；`spawn()` → 新 uid、`dead=false`、满血；
  4. `begin_frame(F+1)`：帧头冲刷该顺延项。
- 期望结果（架构 §2.3 池复用契约 + 本仓先例 homing_projectile.gd:123「uid 双重校验：节点回收复用后 uid 已换（新身份）→ 视为丢失，杜绝错绑」）：ctx.target_uid 与节点现 uid 不一致应诚实丢弃（settle_flush_dead 口径），新敌人零伤害。
- 实际结果：`_flush_pending_head()`（damage_pipeline.gd:372-387）与 `_end_frame_pending_maintenance()` 过期强冲路（:413-422）都只查 `_target_alive`（节点 dead 标志）不查 uid → 幻影伤害全额落新敌（探针实测 Δhp=−10/合并 base，`settle_flush+1`）；且幻影 DamageResult.target_uid 仍旧局 uid，入 `_resolved_queue` 后被 30 帧守卫正常放行派发（龄 1≤30）→ popup/HUD/relic/game_feel 消费死锚事件（旧 uid 跳字/击杀再触发链）。
- 波及面：仅真机自动门开启形态（mobile ∧ 帧率优先 ∧ tier≤2）——恰是本刀的目标深载场景：结 N 1000-2600/s 下顺延对恒存在（帽 48/96 ≪ 需求），敌死亡即时归池 + 每帧出怪复用节点（LIFO 顶=刚归还节点），击杀与顺延并存即触发。合并对的 base 为 ≤12 帧单武器累积，深局武器可对新出生敌一击即杀（击杀数/经验/连杀误计）。跨局 restart 形态已验证**安全**（P2c1：清场同步归还 → 下一帧头全数亡丢，亡丢不耗预算、数量超帽也一帧清空，先于出怪）——开发自述「帧头冲刷先于出怪」的时序在重启形态成立，在同帧击杀→复活形态不成立。
- 修复建议（供开发参考）：`_flush_pending_head` / `_end_frame_pending_maintenance` 在 `_target_alive` 后追加 `int(ctx.target.uid) == ctx.target_uid` 复验（不一致按 settle_flush_dead 诚实丢弃；`_defer_settle` 建仓时同样校验）。

### QA-2（LOW）顺延命中不入幂等缓存：同键 dupe 被当独立命中合并，base 翻倍

- 复现步骤（同套件 P4b，headless 确定性）：`settle_budget_override=1`；`begin_frame(F)`：resolve ctxX（真结算，预算尽）→ resolve ctxY（source=8801, base=10）→ 顺延占位 → 再次 resolve 与 ctxY 同键（同 source/target/frame_stamp/base）。
- 期望结果（damage_pipeline.gd:6「同输入必同输出」+ 幂等短路语义）：同键第二次 resolve 应与顺延前同语义短路（零额外伤害）。
- 实际结果：占位结果不写 `_idempotent_cache` → 二次 resolve 幂等 miss → 预算仍尽 → `_defer_settle` 同对再合并（base 10+10）→ 帧头冲刷落账 −20（预算前语义应 −10）。
- 波及面：现网四路调用方（settle_aoe/projectile/laser/orbit）逐目标每帧至多一次 resolve，同键双发不可达——纯潜伏契约偏差；若未来出现同帧二次命中同键的调用路径会静默双倍伤害。评级 low。
