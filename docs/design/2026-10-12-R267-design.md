### 刀P1：runstart 预热总刀——出发帧位图补烤分帧 + 本局敌变体预热兜底

**症状（真机）**：出发帧 41.6ms（vc71 物步µs 41612，`docs/qa/2026-10-12-R262e-batch-report.md:9` 遗案）；后期每波新怪首见/爆虫潮换脸/Boss 出场单帧 42-181ms 顿挫（「还是卡」战斗期主嫌之一）。

**证据**：
- 出发帧：`start_run` 内第 4 条可执行语句同步调 `PopupGlyphAtlas.ensure_runstart_bake()`（`scripts/loop/game_loop.gd:1676`〔实证〕；未就绪则 `build_all()` 全量 ~42ms，`scripts/ui/popup_glyph_atlas.gd:124-138`〔实证〕；自动档 `runstart_gate()`=mobile，`:116-121`〔实证〕）。微基准冷位图 start_run 整链 42.3-48.1ms（探索轮）/ 本轮复测 32.3ms（§3），热位图 1.3-6.1ms——补烤净贡献 30-47ms 与 vc71 出发帧量级直接闭合。
- 敌变体：惰性首焙根因 = `enemy.gd:2672-2682` `_set_volatile_face`→`TextureFactory.enemy_tex` 首焙（volatile 42.08ms / volatile_scared 50.14ms / boss7 181.29ms 实测，二次命中 0.011ms）；预热队列（`game_loop.gd:2868-2947`〔实证〕，volatile 三脸 `:2915-2916`、boss1-7 双面 `:2926-2930` 均在册）只在 MENU 态 4ms/帧消化（`:639-646`〔实证〕），快开局玩家排不到。
- **〔v2〕现行泵的两个硬约束（评审①核实）**：
  - `_process_tex_prewarm` 对队首 boss 项有挂机门——`game_loop.gd:2969-2972`〔实证〕：`op==0 且 kind 前缀 "boss" 且 _menu_dwell_s < BOSS_PREWARM_IDLE_S → break`（整队暂停，非跳过）；`_menu_dwell_s` 只在 MENU 态累计。**若按 v1 处方把 boss 项提队首，PLAYING 泵会整队停摆**；
  - boss 双面单项 88-245ms、**单项原子不可分**（`game_loop.gd:2953-2956` 注释〔实证〕，R215/R222 实测在案——R222 Fix P 占空还账 `_tex_prewarm_skip`（`:3007-3010`〔实证〕）就是为挂机菜单被逐帧连泵钉死 fps10 而设）；
  - 全冷开局首个字形 cell 含一次性 `_ensure_layout` ≈23.7ms（`popup_glyph_atlas.gd:126-127` 注释〔实证〕），超 4ms 预算 6 倍。

**处方**（v2 重构：波序优先 + 门槛换轨 + layout 单列 + 观测口）：
1. **队列重排 = 波序优先**（非 v1 的「全变体提队首」）：波表 roll 后由 wave_director 提供本局出场 `(kind, 首现波)` 清单，`game_loop` 据此重排 `_tex_prewarm_queue`——wave1 廉价 kind（单项 1-3ms）最前；boss 双面**按各自首现波序**放入对应波次段，不提队首。kind 真源 = `Enemy.visual_kind_for`（与 `game_loop.gd:2905` 同源口径，防映射漂移）。**〔v3〕无尽模式口径**：无尽 = 波表循环重播，循环不引入新 kind → 清单 = 波表全量去重 kind 集，首现波 = 该 kind 首次出场位（含循环首圈）；循环后段无新增项，若实际重排次序非最优属排序次优、非功能坏（评审二轮备注②界定）。
2. **PLAYING 泵（新增渲染轴尾 4ms/帧）带 skip 语义与波次门槛**：
   - 未达门槛的 boss 项**跳过（continue）不 break**——队首 boss 项未放行时，其后的廉价项照常消化，杜绝整队停摆（MENU 态泵原 dwell 门原样保留不动）；
   - boss 项 PLAYING 侧门槛 = 波次感知：`current_wave ≥ boss首现波 − 1` 才可出队（把 88-245ms 原子项从「Boss 出场帧」挪到「出场前一波的低强度窗」）；原子超支沿用 R222 Fix P 占空还账（`_tex_prewarm_skip` 现成机制）。**诚实声明**：原子项无法塞进 4ms 预算，本刀对 boss 双面属**错峰缓解非根治**——工作帧仍 88-245ms 一次、频率摊到 ~1/N 帧；根治需拆 boss 贴图生成为渐进/分块（§5 立项）；
   - LEVEL_UP/PAUSED 不泵（照 R256 口径〔实证 `game_loop.gd:649-655`〕）。
3. **layout 单列通道**：一次性 `_ensure_layout`（≈23.7ms）不进 PLAYING 泵——在**祝福模态开帧**（点出发→模态打开的菜单侧过渡帧，start_run 之前）同步做掉 layout + 前 ≤4 cell（≈35ms 单帧一次性）；若模态流程缺席或玩家秒确认，`start_run` 帧特批兜底（layout+≤2 cell，出发帧 ≤30ms 档，DebugStats 可判读）；PLAYING 泵首帧若仍遇未 layout 的 cell，特批一次并计数（观测口）。**实施轮须先核实模态流程是否恒在**（menu_screen `_blessing_modal` 流程分支）——存在无模态快路径时以 start_run 特批档为兜底主通道。
4. `popup_glyph_atlas.gd` 补口：`unbaked_cells()` 计数 + `ensure_layout()` 单列口（`build_cell` 已在 `:141-144` 幂等）。
5. **观测口（新增 DebugStats）**：`tex_prewarm_frame_us`（每次泵调用实际耗时）、`tex_prewarm_atom_overruns`（超支原子项计数）——验收 e/f 的判读源，也是真机 vc 轮判读口。
6. 锚定 **4 个 `ensure_runstart_bake` 调用点**统一改口径：`game_loop.gd:1406`（continue_endless）/`:1676`（start_run）/`:2245`（restart）/`:3512`（continue 存档）〔实证 grep〕。**〔v2〕勘误：v1 写「notify_new_run 同址四处」不成立——`notify_new_run` 仅 3 处（`:1675/:2243/:3511`），continue_endless（:1406）不调它**；实施按 ensure_runstart_bake 4 点找位，勿按 notify_new_run。
7. 不动什么：**TextureFactory 零改动（仅调用 `enemy_tex`）**；烤内核、bitmap 门回退 Label 路径、MENU 态 dwell 门语义全不动。

### 2.2 架构：一套生成器、双形态落地

新建 `scripts/combat/weapon/melee/crystal_blade_factory.gd`（static 工具，~180-240 行含中文注释/R267 锚）：

### 2.5 性能纪律与低特效降级

1. **静态生成 + 缓存，严禁每帧重建**：烘焙形态键 `"<style>|<t2>|<fill.to_html()>|<quality>"` 进各武器脚本本地 static 缓存（勿写 TextureFactory 共享 `_cache`——`flying_sword_weapon.gd:323` 注释明令先例）；键空间有界 ≈ ≤120 键 × 64²×4B ≈ ≤2MB。即时形态外壳顶点 = 现顶点绕质心外扩一次算好，连同色表 static 缓存（R188⑨ `_poly_cache`/`_line_cache` 同式）。
2. **零 rng**：纯确定性 SDF；判定/结算路径零触碰（「视觉是刀在抡，判定是扇形」解耦契约保持）→ pkg4 seed=42 红线天然满足（仍须跑绿）。
3. **draw call 预算**：ArcSlash 每窗帧 10-12 → 12-14 canvas item（+外壳 1 + 折射亮线 1）；W8 环刀每把 +1；挥斩窗 0.34s 量级增量可忽略且零分配（顶点缓存直出）。
4. **降档矩阵**（照 `elemental_fx_layer.gd:54-55` 预算表 [0,2,4] 先例；档位读法照 `arc_slash._fx_quality()` `:557-562` 钳 [0,2]+mobile 降 1 档镜像口径）：
   - 档 2（高）：全五层（外壳 ×1.32 α0.22 / 过渡 ×1.14 α0.45 / 亮核 α0.92 / 白刃缘 α0.9 / 内折射亮线）；
   - 档 1（中）：砍外壳与折射线（三层：过渡+亮核+刃缘）；
   - 档 0（低）：单层 α0.85 平涂 + 刃缘线，残影砍半（2→1）；
   - 降档参数进缓存键（防运行中改档后旧键遮蔽）。KIN 豁免路径不参与降档（本就零增量）。
5. 预烤可选进 `prewarm_shared()`（`texture_factory.gd:156-169`）缺省色域，首击零冷 miss。
6. **与刀P1的边界**：视觉刀禁止触碰 `texture_factory.gd` 的 `enemy_tex` 与预热队列消费语义（op:0-7），刀P1 依赖之；boomerang_tex/图标/委托臂是不同函数，无文本冲突。
