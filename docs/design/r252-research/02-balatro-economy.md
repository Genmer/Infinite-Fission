# R252 调研-02：Balatro 辅系统（经济 / 星球·塔罗·补牌包 / 负面券与风险契约）

摘要：Balatro 的辅系统本质是把「钱」和「卡库」都做成可构筑对象——利息与上限让金币有了时间价值和强制消费节拍，星球/塔罗/补牌包让玩家用金钱去定向雕刻构筑方向而非被动吃随机，负面版面与玻璃牌/信用券/跳盲注标签则构成一族「用容量、寿命或未来收益做抵押」的风险契约。对本作《Infinite Fission》的启示是：困难难度构筑不起来的根因之一是「货架随机与玩家意图脱钩」，Balatro 的 Telescope（货架偏向已投入方向）、塔罗改牌（删卡/转换）、资产变现（拆重建）三件套正是补上这一环的机制语言。以下 11 个条目均给出按本作 RelicData（listen_events + effect_id + params）schema 的落地方案与三档实现代价评估。

> 调研方式：联网调研（balatrogame.fandom.com / balatrowiki.org / IGN 等，检索日期 2026-10-10）+ 本仓库代码核对（RelicData schema、RelicHandler、金币掉账、商店占位）。数值细节以 wiki 为准，文中已注明。
> 本作代码锚点：`repo/scripts/core/data/resources/relic_data.gd:6-16`（遗物 schema）；`repo/scripts/loop/relic_handler.gd:1-26`（事件分发 + 既有遗物语义）；`repo/scripts/loop/game_loop.gd:3358-3361`（金币掉账/AFF_GOLD）；`repo/scripts/meta/mechanic_gate.gd`（大关节奏与诅咒博弈）。

## 1. 利息与金币上限——钱的时间价值
- 原作规则：每回合结算时按持有金币每 $5 生 $1 利息，基础上限 $5/轮（Seed Money 券提至 $10、Money Tree 至 $20），金币硬上限 $400；小丑「To the Moon」在此基础上每 $5 额外 +$1（受券上限放大）；绿牌组则彻底放弃利息换出牌资源。
- 构筑价值：金币从「消费品」变成「成长曲线的第二轴」——花掉=立即战力，攒着=下一轮更多本金，形成每一轮的 time-value 决策；$400 硬上限是隐形节拍器，攒到上限就被强制推回消费侧，防止滚雪球躺赢。这是「风险契约」里最温和的一种：延迟满足。
- 本作适配改造：金币经济已存在（`game_loop.gd:3358` gold_drop 掉账、AFF_GOLD 点金、丰饶/富矿祝福倍率）但目前只是黑市货币。设计遗物 **REL_COMPOUND（复利芯片）**：每波结算时未消费金币生息 `floor(gold/生息除数)`，封顶 params 生息上限，金币总量设 params 硬上限——生息除数/上限/金币帽全部走 params 数据驱动；与 REL_BLACK_MARKET（商店波排程，`relic_handler.gd:26` 占位）联动后形成「攒—花」循环。
- 实现代价预估：需新消费点（利息本体纯 params 可算，但没有商店波落地就是死钱；商店 UI `scripts/ui/shop_ui.gd` 已存在，缺口在金币消费入口与波结算钩子）。

## 2. 星球牌·构筑押注与货架显影（Telescope）
- 原作规则：12 张星球牌各对应一种牌型，使用后永久（本局）提升该牌型的底注 Chips×Mult（每级 +1 Mult、+10~50 Chips，档位随牌型强度递增）；Telescope 券让星球包必出「你最常打的牌型」对应的星球牌。
- 构筑价值：星球牌不是增益而是**押注**——先反复给某牌型练级，再去拿「读该牌型」的小丑，构筑是延迟组装的：投资在前、兑现在后；Telescope 则把随机货架与玩家已投入的方向焊死，形成正反馈。Observatory 券进一步把星球牌从一次性消耗变成持续引擎（持有即给对应牌型乘区）。
- 本作适配改造：这是对「困难难度构筑不起来」最对症的一条。遗物 **REL_FOCUS（引力聚焦）**：开局选定（或按本波伤害占比自动认定）主武器族，此后词条卡货架对该族词条加权、且高权重随投入加深——即 Telescope 语义的「货架显影」；再配一层星球语义：词条卡中混入「星尘卡」，使用后永久提升该武器族在本局的精通档位（精通系统已在 MechanicGate 第 1 关主题中存在，见 `mechanic_gate.gd` MAP_INTROS）。
- 实现代价预估：货架加权需改 card_generator 出卡权重——效果处理器新语义「卡池权重偏向」，半数据驱动；星尘升级精通如复用现有精通成长曲线则纯 params。

## 3. 塔罗·牌库雕刻（删卡 / 复制 / 转花色）
- 原作规则：塔罗牌不直接给战力而是编辑牌库——The Hanged Man 销毁至多 2 张选中牌（削卡提均值）、Strength 将至多 2 张升 1 点、Death 让左牌复制右牌、Star/Moon/Sun/World 把至多 3 张转成指定花色。
- 构筑价值：把构筑从「拿什么」扩展到「**删什么、改什么**」：删弱卡是隐性乘区（抽到核心件概率上升），花色转换把「读花色的条件小丑」从概率条件变成确定性条件——玩家亲手把条件引擎焊死。
- 本作适配改造：词条/卡牌流已有三选一与诅咒（REL_GAMBLER，`relic_handler.gd:19-21`），但「已获得的构筑」不可编辑。设计两条：**REL_CHISEL（剔除凿）**：每次三选一可用金币从词条池中永久剔除一个低价值词条（后续卡池均值上升）；**REL_TRANSMUTE（元素嬗变）**：将一个已持有元素词条转换为同稀有度的另一元素词条（如火→冰），玩家可定向切换元素反应轴（碎裂/冻结/超导，见 `mechanic_gate.gd` 第 2~3 关反应表）——这就是「转花色」语义。
- 实现代价预估：需新消费点（需要「已持有词条可被修改/删除」的操作入口与 UI，词条数据本体是数据驱动的，缺的是编辑动作与结算刷新）。

## 4. 补牌包·付费定向补给与选择权定价
- 原作规则：商店出售五族补牌包——Standard/Arcana/Celestial/Buffoon/Spectral（常规 $4 选 1 张），Jumbo/Mega 版加价（$6~8）给更多内容与 2~3 次选择；包是「按轴定向补货」，比商店白嫖位多一次定向选择权。
- 构筑价值：把「随机刷新等货」改造成「缺哪轴买哪轴」；Mega 包定价揭示了一个隐藏商品——**选择权本身就是商品**（多选一=降低方差，玩家为确定性付费）。
- 本作适配改造：商店波（BLACK_MARKET 占位）落地时直接采用包结构而非裸货架：**定向包**=「武器词条包 / 元素反应包 / 遗物包 / 诅咒包」，金币购买、N 选 1，Mega 版 3 选 2 加价；词缀包内必含 1 张该轴核心件作保底。与条目 1 利息形成闭环：金币从战斗掉账来 → 进包 → 变战力。
- 实现代价预估：需新消费点（金币计价 + 包 UI；可挂在已有 shop_ui.gd 上，包内容本身走 RelicData/词条 params 生成）。

## 5. 券树·商店基建投资（Vouchers）
- 原作规则：32 张券、16 对（二级券需先买一级），花钱永久改写商店规则本身：Overstock 货架 +1、Reroll Surplus 降重随价、Clearance Sale 全场 25% 折扣、Crystal Ball 提高塔罗包产出等；部分券解锁还与累计消费额挂钩。
- 构筑价值：把「商店」本身变成构筑对象——经济基建投资有复利，且券树的先后依赖构成一棵微型科技树，消费顺序本身就是 build（先买货架位还是先买折扣是策略分歧点）。
- 本作适配改造：本作已有「刷新次数」字段（`game_loop.gd:3014` 快照覆盖提及）与 REL_WORDS_TIDE 单波重随、REL_OVERCLOCK 稀有度保底——券 = 把这些单波效果常驻化/参数化的遗物子类。设计 **REL_TIER 券位**：`params = {货架数+, 重随价-, 折扣%, 保底档}`，随大关解锁二级券（复用 MechanicGate 大关节奏表，`mechanic_gate.gd`），形成「第 2 关买基建、第 4 关换质变」的经济科技线。
- 实现代价预估：纯数据驱动（全部落在既有货架数/重随/稀有度参数上，前提是商店波先落地）。

## 6. 负面版面（Negative）·容量压缩奖励
- 原作规则：负面版面的小丑不占小丑位（等效 +1 槽），获取渠道极稀：商店约 0.3% 概率、Boss 盲注跳过的 Negative Tag、灵质牌 Ectoplasm（付 -1 手牌上限的永久代价换取）。
- 构筑价值：高稀有奖励不加个体数值而加**容量**——后期构筑的真瓶颈是槽数不是倍率；Ectoplasm 版本还顺手示范了「容量换缺陷」的风险定价。
- 本作适配改造：本作遗物每场每件唯一（`relic_data.gd:9` 注释）无槽位约束，真正的容量轴是**词条层数上限与满层质变**（第 4 关「词条满层数值 ×1.6」）。设计 **REL_PHANTOM（虚体槽）**：指定一个词条的层数上限 +params 层数（突破满层质变线）；高风险变体走 Ectoplasm 语义：换容量但带一个永久诅咒词条（与第 5 关诅咒博弈主题呼应，`mechanic_gate.gd` MAP_INTROS）。
- 实现代价预估：纯数据驱动（若词条层数上限已是每词条 params 可覆写位；需确认满层质变判定读的是不是同一个上限字段）。

## 7. 玻璃牌·自毁爆伤（风险契约 I）
- 原作规则：玻璃增强牌计分时给 ×2 Mult，但每轮计分结束后 1/4 概率永久损毁。
- 构筑价值：给最高倍率标上「寿命」的价格——玩家按期望主动买卖短期爆发；配复制/再生玻璃的组件后能长出一整条「易碎构筑轴」，风险由玩家组合控制在收益线附近。
- 本作适配改造：弹幕游戏天然有「弹药」隐喻。遗物 **REL_GLASS_BULLET（玻璃弹头）**：params `{充能秒数, 爆发弹数, 倍率, 代价}`——每充能 N 秒，接下来 M 发投射物命中走独立乘区池 ×倍率（复用 `relic_handler.gd:13-16` 的 inject_hit_mult_pools 注入路径），代价为随机移除一个已持有词条的 1 层；词条层数充裕的构筑吃这口红利，空层构筑自爆。
- 实现代价预估：需新效果处理器（伤害爆发+层数扣除的复合语义），但乘区注入与层数数据均已有——半数据驱动。

## 8. 信用券·负债消费（风险契约 II）
- 原作规则：Credit Card 券允许金币透支至 -$20——「买不起」从死墙变成可跨过去的时间换空间，靠后续回合收入偿债。
- 构筑价值：负债把关键件的获取时点提前，而 Balatro 的关键件（核心小丑）是复利型的——早一轮拿到等于多吃数轮收益；与利息体系互为镜像（正余额生息、负余额停息），赌的是「未来的我」还得起。
- 本作适配改造：配合商店波设计 **REL_CREDIT（赊购契约）**：金币可透支至 -params 债务上限购买货架件，此后每波结算自动扣除 params 偿还额（或按利息倒扣）；债务未清时禁买下一件——把条目 1 的利息轴补成对称系统。
- 实现代价预估：需新消费点（负余额状态机 + 每波偿债 tick；数值本身纯 params）。

## 9. 跳盲注标签（Tags）·当期换期货（风险契约 III）
- 原作规则：跳过一个小盲/大盲注即放弃该盲注的金钱奖励，换一张标签期货：Investment Tag（下个 Boss 盲注后 +$25）、Economy Tag（金钱翻倍、上限 +$40）、Negative Tag（下个小丑免费且负面）、Double Tag（复制下一张标签）；社区公认多数标签是陷阱——期货定价失误就白送。
- 构筑价值：这是最显式的**契约界面**：把「放弃确定性收益」做成可点选的合同，风险定价权完全交给玩家；Double Tag 还让期货可以指数化堆叠，产生「囤标签」子构筑。
- 本作适配改造：本作有天然同构物——波次。遗物 **REL_FUTURES（期货契约）**：三选一界面新增「跳过本次词条奖励」选项，换取期货效果（params 选表：下波金币翻倍（设帽）/ 下个 Boss 波后必出高稀有词条 / 下次三选一变四选一无诅咒），兑现钩子挂 listen_events 的 Boss 波完成事件。困难难度下这给「现在打不过、赌两波后翻盘」一条合法路径。
- 实现代价预估：需新消费点（跳过入口 + 期货兑现监听；兑现效果若复用既有保底/重随语义则纯 params）。

## 10. 资产变现·Hermit/Temperance 与构筑转向
- 原作规则：Hermit 塔罗将持有金钱翻倍（至多 +$20）；Temperance 一次性给出全部小丑的总卖价（至多 $50）——卖价是沉没在构筑里的第二账本，可以随时被变现。
- 构筑价值：把「拆构筑」从失败止损升格为主动策略：路线走死时，把旧组件整体卖掉换现金重启新轴（pivot）；卖价定价规则（稀有度/叠数）让「持有什么」本身有资产属性。
- 本作适配改造：解决「困难难度构筑起不来」的最后一环——**起不来的构筑要能拆了重来**。遗物 **REL_LIQUIDATE（清算人）**：波间可将已持有遗物/词条按稀有度函数（params 定价表）卖出换金币；与商店波、券树形成「拆—买—转向」的重建闭环。可再配 Hermit 语义：本波未受击则金币结算 ×params 翻倍系数（设帽），奖励弹幕生存里的无伤技术。
- 实现代价预估：需新消费点（卖出操作 UI + 定价规则 + 遗物移除的运行时清理——owned 列表已有，缺的是反向卸载语义）。

## 11. Ankh·孤注一掷的构筑收敛（风险契约 IV）
- 原作规则：Ankh 灵质牌随机选定 1 个小丑复制一份，并**摧毁其余全部小丑**（负面版面的复制不保留负面）——全押按钮，目标随机、代价不可逆。
- 构筑价值：把构筑收敛变成一场可见的豪赌：普通局做出「双核心」的指数形态只此一途，而随机目标保证它永远是赌局不是操作；正因为狠，它成为整个游戏最富戏剧性的资源转化件。
- 本作适配改造：直接照搬对玩家过狠，改造成**词条版全押**：REL_ALL_IN（孤注）：三选一时的付费选项——将所有已持有词条的层数清空，层数总和按 params 转折算率灌入当前伤害最高/随机的一个词条（元素收束），被清空词条进入本局禁用池。困难难度下「平均词条太弱」时，这是把平庸构筑压缩成单点超载的最后手段。
- 实现代价预估：需新系统语义（词条层数批量转移 + 禁用池；层数数据与乘区已数据化，缺的是跨词条转移的结算规则与 UI 确认流）。

## 对「困难难度构筑不起来」的三条落点（按优先级）
1. **先给货架装 Telescope（条目 2）**：让随机供给跟随玩家已投入的方向，构筑的正反馈才转得起来——这是成本最低、收益最直接的一条。
2. **再给失败兜底资产变现（条目 10）**：走死的构筑可以拆掉重来，玩家才敢在困难难度下实验，而不是等死。
3. **最后接经济闭环（条目 1/4/5）**：金币有生息、有上限、有定向包和券树，钱才会从「掉落物」变成「构筑资源」。风险契约四件套（条目 7/8/9/11）作为困难难度的调味剂后置上线。
