## 2. 冻结的 PerfGovernor API 与 DebugStats 计数器名单

### 2.1 PerfGovernor（autoload/perf_governor.gd，注册名 `PerfGovernor`；主控决策#2 照抄 + 实现细节）

```gdscript
# extends Node；_ready 设 process_mode = Node.PROCESS_MODE_ALWAYS
# 静态读口（消费方：enemy.gd / player.gd / ballistic_weapon.gd / homing_weapon.gd /
#          trait_effect_bounce.gd / mirror_weapon.gd——按 §1 各包接线）

static var tier_override: int = -1          # 测试注入 1..3；-1=真值
static var mode_override: int = -1          # 测试注入 0/1；-1=真值
static var transitions: int = 0             # 档变计数（含测试注入驱动的档变）
static func fx_quality_cap() -> int         # tier→fx_quality 帽：3→2 / 2→1 / 1→0
                                            # 生效门：tier_override∈[1,3] 时按注入值映射（测试直驱，无视平台）；
                                            # 否则 OS.has_feature("mobile") 时按 tier 映射；
                                            # 非mobile 且无注入 → 恒 2（零扰动桌面/headless 既有口径，
                                            # 照 R203 mobile 门先例 enemy.gd:315-322——r202_g3/fx_quality
                                            # 旧断言在默认 tier=3 下逐位不变）

# 常量（照抄主控冻结）
const FRAME_DROP_RATIO := 0.90
const FRAME_RECOVER_RATIO := 0.95
const FX_DROP_RATIO := 0.70
const FX_RECOVER_RATIO := 0.85
const DROP_SUSTAIN_S := 2.0
const RECOVER_SUSTAIN_S := 5.0
const FX_FLOOR_TIER := 2
const EMA_ALPHA := 0.25
const SAMPLE_S := 0.5

# 可测性注入口（本契约补充，不进产品读口）

```

行为冻结：

1. `_process` 每 **0.5s**（SAMPLE_S）采 `Engine.get_frames_per_second()` 入 EMA（EMA_ALPHA=0.25；EMA 未初始化时首采直接赋值；`_ema_inject≥0` 时用注入值）。PROCESS_MODE_ALWAYS——暂停/选卡期采样不停。
2. `target = clampi(int(Meta.settings("fps_cap")), 1, 120)`——fps_cap=0（不限）时取 120。
3. **仅战斗态且非 paused 才累计转换计时**：战斗态判定=GameLoop 解析（照 `DebugStats._diag_find_game_loop()` debug_stats.gd:94-106 先例：root "Main" 或 has_method("diag_counts") 扫描，WeakRef 缓存）且 `state == PLAYING` 且 `not tree.paused`。选卡/暂停期**挂起**（计时冻结不清零、不清 EMA——主控决策#2 原文）。
4. 转换规则（计时到持续阈值才动档；档变 `transitions += 1` 并即时生效——fx_quality_cap() 即时读 tier 无需推送）：
   - **帧率优先**：EMA < target×0.90 持续 2.0s → tier−1（可降至 1）；EMA > target×0.95 持续 5.0s → tier+1（至 3）。
   - **特效优先**：EMA < target×0.70 持续 2.0s → tier−1（**地板 2**）；EMA > target×0.85 持续 5.0s → tier+1（至 3）。
   - 降档/升档计时器独立（各自持续判定；条件翻转即清零该侧计时）。
5. 模式切换（settings_changed("perf_mode") 订阅 或 mode_override 变化）：tier 保持当前值、双侧转换计时清零重累计（防切换瞬间假触发）；EMA 保留。
6. tier_override 注入时 tier 直接取注入值（不跑转换），transitions 不增（注入是测试不是真转换）——**注意**：注入驱动的档变不计数，transitions 只记真采样驱动的档变。
7. **本轮应用面仅 Enemy.fx_quality 映射写点（A5）**；其余消费点（刀12 配额 C7、刀13 四值 C2/C3/C11、刀14 预算 C4）全部经 `frame_priority()` 分支，归火段数值包按本契约接线。刀1-11 工程刀两种模式都生效、无模式分支（主控决策#8）。
