## 2. 伤害结算管线（最终裁定版，实现契约）

### 2.1 主公式（F1 落地展开）

```
面板段    S = ATK_base × (1 + Σ Add衰减后) + Flat          # Add 池 F3 几何衰减；Flat 比例钳制(≤50% S)
乘区段    M = Π_{p ∈ 独立乘区池} (1 + agg_p)               # agg_p = 合并加算贡献，单区 ≤ cap_pool_p
私有段    L = Π_{l ∈ Local池} (1 + agg_l)                  # 光束灼焦等武器私有，自有 cap_local
暴击因子  C = (roll 命中) ? crit_mult : 1.0                # 独立掷骰；crit_mult = 武器字段(默认2.0)+词条
目标侧    V = enemy_resist(element) × (1 + 易伤等状态修正)
最终      Final = clamp(S × min(M, 8.0) × L × C × V, 0, ATK_base × 500)   # ×500 保险钳制+审计
```

### 2.2 DamageContext（结算请求输入）

| 字段 | 类型 | 说明 |
|---|---|---|
| `source_uid` | int | 来源实例 UID（幂等键组成部分） |
| `target` | Enemy | 目标 |
| `base_atk` | float | 面板 ATK（来源侧已聚合） |
| `add_ids[]` | Array[String] | 加算词条 ID 列表（池内聚合） |
| `flat_bonus` | float | 平坦加成 |
| `mult_pools[]` | Array[Dict] | `{pool_id, source_uid, contrib}` 三元组列表 |
| `local_pools[]` | Array[Dict] | 同上，Local 池 |
| `crit_chance / crit_mult` | float | 暴击参数（来源武器+词条聚合） |
| `element` | enum | KIN / FIR / ICE / LTG |
| `hit_flags` | int 位标志 | IS_BOUNCE / AFTER_PIERCE / IS_SPLIT_CHILD / IS_REACTION 等（供词条条件自评） |
| `frame_stamp` | int | 帧号（幂等键） |

### 2.3 结算步骤序（M-12 契约，九步）

1. 幂等检查：`(source_uid, target, frame_stamp)` 已结算 → 短路返回缓存结果
2. 目标存活检查（死亡短路）
3. Add 池聚合（同 ID 衰减 F3，负贡献全额）
4. Flat 加入（比例钳制）
5. 乘区聚合：多实例合并加算 → 同实例重入取最大 → 单区 cap_pool_p → 池数名额 ≤8 → 整体钳制 8.0
6. Local 池独立聚合（不入全局名额）
7. 暴击掷骰（可注入固定种子的 RNG）
8. 目标侧修正（抗性 × 易伤/状态）
9. 终值钳制 + 审计遥测（`mult_final`, `pool_count`, `clamped` 标志）→ 广播 EventBus（命中/暴击/击杀，含乘区明细）

### 2.4 元素系统（最终口径）

- **附着模型**：`stack += attach_val`，比例衰减 `stack *= (1 − λ_ele×dt)`，满槽触发状态；稳态免疫线由 λ 决定
- **状态**：点燃（DOT 15%ATK/0.5s×3s×5层）、冰冻（减速 40% 2s；3 层→易伤 ×1.25 3s）、感电（连锁 3 目标/160px/35%每跳/深度 2）
- **反应**（两元素均附着且非 CD 内触发）：碎裂（FIR+ICE，×2.0 独立结算）、过载（FIR+LTG，120% ATK）、超导（ICE+LTG，全抗 −30% 6s）；`cd_rxn = 2s`；反应伤害 = 触发伤害快照 × 系数（独立结算，F20）
- **免疫**：`immune_mask` 矩阵（状态 × 敌人 tag）；Boss 免疫定身
- 三重反应"三相湮灭"框架定义，默认关闭

### 2.5 词条注册表数据契约（L1 守门）

每个词条 .tres 必填：`id`、`pool`（ADD / MULT / LOCAL / MECH / ELEM）、数值字段、事件钩子声明（OnSpawn/OnTick/OnHit/OnPierce/OnBounce/OnExpire）、`stack_max`、`inheritable`、`tags`。
启动校验：pool 不合法 / ADD 缺 `decay_delta` / δ > 0.92 / MULT 缺 `cap_pool_p` → 剔除条目 + 错误清单（不崩溃，降级运行）。

- **M-01**：帧处理顺序固定（输入→玩家→武器开火→投射物运动/碰撞→敌人 AI→波次生成→特效→UI）；全局 time_scale 唯一持有者
