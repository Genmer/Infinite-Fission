### 0.2 伤害结算公式（本文采用的完整展开）

```
Final = (BaseATK × (1 + ΣAdd_ATK) + Flat) × Π(1 + Indep_i) × CritFactor
ΣAdd_ATK：所有 ATK% 类词条合并求和（同类同池合并）
Indep_i：独立乘区；同条件同类型乘区「合并为一区」：区值 = 1 + Σ(词条区贡献)；条件不同的区之间连乘
CritFactor = 1 + crit_rate × (crit_dmg − 1)，作为最后一个独立因子 `[!]`（暴击位置待 A2 裁定）
连乘积封顶：Π(1+Indep_i) ≤ cap_synergy_product = 8.0 `[!]`
射速：rate_final = rate_base × (1 + ΣROF)，≤ cap_rof_per_weapon
冷却：cd_final = cd_base × (1 − ΣCDR)，ΣCDR ≤ 0.60
```

## 1. 基准标尺

### 1.1 TTK 目标（设计中心带）

| 目标 | 区间 | 中心值 | 口径 |
|---|---|---|---|
| 普通小怪 TTK | 1.0 ~ 1.5 s | **1.2 s** | 玩家全部火力集火单体，面板 DPS |
| 精英 TTK | 4 ~ 6 s | **5.0 s** | 同上，@对应波次 |
| Boss TTK | 25 ~ 40 s | **32 s** | 同上，@对应波次 |
| 软边界 | 0.8 ~ 1.8 s（小怪） | — | 单套构筑峰值允许越出中心带 ±20%，全场期望必须落回中心带 |

### 1.2 玩家基准 DPS@0 升级

| 参数 | 初值 | 推导 |
|---|---|---|
| `base_dps_w1` | **60** | 手枪：12 ATK × 5.0 发/s（面板，不含暴） |
| `dps_exp(w)`（面板期望） | 60 × 1.12^(w−1) | 每波期望成长 ×1.12，来源拆解见 1.5 |
| 含暴期望(w1) | 63 | 60 × (1 + 5%×(2.0−1)) |

**核心恒等式（全表锚点）**：

```
HP_小怪(w) = dps_exp(w) × 1.2 = 72 × 1.12^(w−1)
HP_精英(w) = dps_exp(w) × 5.0 = 300 × 1.12^(w−1)   （= 小怪 × 4.2）
HP_Boss(w) = dps_exp(w) × 32  = 1920 × 1.12^(w−1)
```

TTK 在任意波次恒为 1.2 / 5.0 / 32 s —— 数值自洽由「敌我同速成长」保证。

### 1.3 波次时长

| 参数 | 初值 | 说明 |
|---|---|---|
| `spawn_window(w)` | 18 + 0.4×w s | 敌人刷新窗口（w1: 18.4s → w30: 30s） |
| `loot_buffer` | 3 s | 全清后拾取缓冲，随后开下一波 |
| `wave_hard_cap` | spawn_window + 8 s | 硬上限：到时未清完强制叠波（压力叠加） |
| `boss_wave_duration` | — | Boss 波无固定时长，Boss 存活期间持续刷伴随怪 |
| `batches(w)` | 3 + floor(w/6) | 每波刷新批次数 |
| `tp_jitter` | ±10% | 运行时威胁预算随机浮动（±15% 为表内容差） |

### 1.4 波内敌人预算（威胁点 Threat Points）

| 参数 | 初值 |
|---|---|
| `tp_formula(w)` | TP = 14 + 3.2×w（w1: 17.2 → w30: 110） |
| `tp_elite_wave_mult` | ×1.25（含精英的波） |
| TP 成本 | 杂兵 Grunt=1.0 / 疾冲 Runner=1.2 / 重甲 Bastion=4.0 / 自爆 Volatile=1.5 / 精英=16 / Boss 不计 |
| `tp_formula(w>30)` | TP = 110 × 1.03^(w−30)（无尽模式） |

### 1.5 群体效率系数 k_aoe 与清屏校验

竖屏敌人成群直线扑来，穿透/分裂/溅射使一发弹药命中多目标。定义：

| 参数 | 初值 | 说明 |
|---|---|---|
| `k_aoe(w)` 期望 | w1: 1.3 → w5: 1.8 → w10: 2.2 → w20: 2.5 → w30: 2.6 | 由多武器 + 穿透/分裂/反弹词条自然实现 |
| 有效清屏 DPS | dps_exp(w) × k_aoe(w) | 波预算校验用 |
| 波总 HP 估算 | `wave_hp(w) ≈ TP(w) × HP_小怪(w) × 0.75` | 0.75 为混合兵种 HP/TP 折算系数 |
| 清屏校验式 | wave_hp(w) ≤ 有效清屏 DPS × (spawn_window + 8) × 0.9 | 必须逐波成立（抽样验证见 §8.3） |

**玩家 DPS 期望成长来源拆解（每波 ×1.12 的构成）**：

| 来源 | 每波贡献 | 说明 |
|---|---|---|
| 卡牌（每波期望 1.2 + 0.02w 张，每张等效 +6% 输出） | ×1.08~1.10 | 约 30% 的卡为生存/机制卡，稀释直接输出 |
| 武器槽新增（w3 / w7 / w10 后 / w20 后） | 跳升 +25% / +22% / +18% / +12% | 跳升当波高于曲线 8~12%，随后卡牌收益摊薄平滑回曲线 |
| 武器精通（武器 L2~L5） | 计入卡牌贡献 | 升级卡占白卡权重 12% |

### 2.1 全局成长公式

```
scale_hp(w)  = 1.12^(w−1)
scale_dmg(w) = 1.06^(w−1)
scale_spd(w) = 1 + 0.008×(w−1)
scale_exp(w) = 1.085^(w−1)

HP_final   = hp_base × scale_hp(w)
Dmg_final  = dmg_base × scale_dmg(w)          # 碰撞/弹幕伤害
Speed_final= spd_base × scale_spd(w)
EXP_final  = exp_base × scale_exp(w)
```

## 4. 词条（Affix/Trait）数值表 —— 28 条

### 4.1 池规则（本文假设，`[!]` 待 A2）

1. **加算池**：同属性词条数值直接相加并入 `ΣAdd`（ATK 类一个池、射速类一个池、CDR 一个池……）。
2. **独立乘区**：每条乘区词条声明「条件 + 区类型」。**条件相同且区类型相同 → 合并为一个乘区**，区值 = 1 + Σ(各条贡献)；条件不同 → 各自独立连乘。例：两张「冰渊裁决 ×1.5」→ 单区 ×2.0；「冰渊 ×1.5」×「烈焰吞噬 ×1.35」同时满足 → ×1.5 × 1.35。

4. 元素类词条不改伤害公式，驱动**附着/反应系统**（§4.5），反应伤害走独立乘区。

## 9. 自洽性验证与防崩坏护栏

### 9.1 崩坏压力测试（最坏情形手算）

极端假设 @w15（面板期望 293）：玩家天胡连拿 3 张金/紫乘区 + 全加算：
- ΣAdd_ATK 堆满（AFF_ATK×3 + 遗物等）= +45%+10% = +55%
- 乘区：冰渊 ×1.5 × 烈焰 ×1.35 × 反弹 ×1.4 × 背水 ×1.6 = ×4.536（未触 cap 8.0）
- 合计瞬时峰值 = ×1.55 × 4.536 ≈ **×7.03** → 峰值 TTK = 352/(293×7.03) ≈ 0.17s

判定：**不崩**。理由：(a) 峰值需 4 条件同时成立（双状态附着 + 反弹后 + 残血），场均覆盖率 <25%；(b) 独立乘区封顶 8.0 硬顶；(c) 加算池边际递减（叠 3 张仅 +45%）；(d) 波难度由 TP 总量与精英/Boss 承担，单体秒杀不改变清屏预算校验。**质变感来自覆盖率提升而非瞬时倍率无界** —— 符合需求「吃一两个 Buff 不崩坏」。
