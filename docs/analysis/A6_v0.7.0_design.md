## 2. 芯片运行时（U2，scripts/loop/chip_handler.gd）

- 常量：`MAX_CHIP_SLOTS=3`、`CHIP_RNG_SEED=4242`、`CONVERT_RATIO=0.5`。
- 字段：registry/player 注入；`rng`（默认 seed 4242，`set_rng_seed` 可注入）；`unlocked_slots`；
  `equipped: Array[Dictionary]`（{chip: ChipData, rarity: int}）；遥测 chips_granted / chips_converted /
  gold_from_convert。
- 槽位解锁：EventBus 新信号 `chip_slot_unlocked(slot:int)`；WaveDirector.start_wave 尾部
  （emit_wave_started 后）`match p_wave: 1→1 / 10→2 / 20→3`；ChipHandler 端
  `unlocked_slots = maxi(old, clampi(slot, 1, 3))`（幂等取大 + 越界钳）。
  〔审查裁定 2026-09-01〕**free_slots() = maxi(unlocked_slots − equipped.size(), 0)**——解锁门控
  真实生效（未解锁=0 空槽；商店购买五查与 Boss 掉落转金币共用本口径），不再是无语义状态。
- `equip(id, rarity)` 五门 fail-fast：registry null / get_chip null / 已装备 / free_slots ≤0 → false；
  成功 → 入列 + **max_hp 特殊键**（player.max_hp += v；hp = minf(hp+v, 新 max_hp)）+ 全武器
  `invalidate_panel()`；chips_granted+1。
- `stat_bonus(stat)` = Σ 已装备同 stat_key 的 values[rarity]（消费点唯一问询口）。
- `slot_snapshot()` → Array[Dictionary] 恒 3 格：{chip_id, display_name, stat_key, rarity, value_text}
  / 空槽 {}。value_text：max_hp → "+80"；其余 → "+35%"。
- `roll_rarity(wave)`：单一真源 = `CardGenerator.rarity_weights_for(p_wave)`（v0.7.0 自 _roll_rarity
  提取的静态纯函数，不改实例状态）+ 自有 rng 流。
- `reset_run()`：equipped 清空 + unlocked_slots=0 + rng 重播种 + 遥测清零（不跨局）。

## 3. 芯片结算接线（U3，护栏级）

### 3.1 管线 ⑥b 芯片独立乘区段

- `DamageContext.chip_entries: Array[Dictionary]`（{stat: StringName, contrib: float}）。
- `ModifierStack.aggregate_chip(entries, cap)`：负贡献钳 0；Σ > cap_chip_zone → 截断 +
  `audit.clamped_chip`；`chip_product = 1 + Σ_clamped`（audit.chip_product 同步）。
- `DamagePipeline.resolve()` 在 ⑥_local 之后插 **⑥b `_aggregate_chip`**（读
  `GameConfig.balance.cap_chip_zone`，schema 默认 1.0，合法域 (0,4] 非致命校验）。
- **终值公式（v0.7.0）**：`joint = min(mult_product × chip_product, cap_prod)`；
  `raw = S × joint × L × C × V`。joint 触发钳 → 置位既有 `audit.compressed` 语义；
  audit.ratio 分母口径同改用 joint。
- **恒等性**：chip_product = 1.0 时与 v0.6.0 公式逐位恒等（pkg0~pkg6 fixed-seed 全量回归共证）。

### 3.2 ★ AOE/DOT/反应不吃芯片 ATK 段（契约）

- `settle_aoe`（死亡新星/冲击波/AOE 通道）自建 ctx，**不注入 chip_entries**；
- DOT 跳伤/感电连锁（ElementalSystem 自建 ctx）**不含 chip_entries**；
- 反应通道 `resolve_reaction` 不走 ⑥b（`result.chip_product` 恒 1.0）——反应基数是 S 快照；
- 直击通道 = 投射物（`projectile_base._build_damage_ctx` 读快照键 `chip_atk_pct`）+
  武器直结（`weapon_base.build_damage_context`），两处注入 `{stat: &"atk_pct", contrib: chip_pct}`。

### 3.3 面板折算与射速

- `weapon_base.build_panel_snapshot` 增芯片 crit 折算：`crit_rate = clamp(表值 + Σadd_crit + K_crit, 0, cap)`、
  `crit_mult = 表值 + Σadd_critdmg + K_critdmg`（K = chip_handler.stat_bonus，null 守卫）；
  快照增键 `"chip_atk_pct"`；新增公开 `invalidate_panel()`。
- 射速：BALLISTIC `rof = clamp(表值 × (1+Σadd_rof) × (1+K_rof), 0.1, 30)`（铁律 ≤30 保留）；
  其余形态 `interval = cd × (1−cdr) / (1+K_rof)`。

### 3.4 消费点（GameLoop / ElementalSystem）

| 消费点 | 公式 | 边界 |
|---|---|---|
| `_add_gold(delta)` | 正增量 ×(1+K_gold) | **负数消费不缩放** |
| `_on_enemy_killed_drop_xp` | exp_value × relic.xp_mult() × (1+K_xp) | — |
| `ElementalSystem.apply_attach` | 入口统一 ×(1+K_attach) | 覆盖弹载荷与 ELE 词条请求两条路 |
| `Player.respawn()` | max_hp 重导出基线（global_constants `player_base_hp`） | 消除芯片/商店加成跨局残留 |

- GameLoop 组装：chip_handler 在 relic_handler 之后、spawner add_child 之前；player.setup deps
  增 `"chip_handler"`（透传武器 setup）；`elemental.chip_handler` 注入。
