## 4. 诅咒运行时（V6）

- **CurseHandler**（scripts/loop/curse_handler.gd）：0~5 层（MAX_CURSE_LAYERS=5）；
  每层三乘区 DMG_TAKEN_PER_LAYER=0.08 / GOLD_DROP_PER_LAYER=0.15 / MAXHP_PER_LAYER=0.04。
- add_curse/remove_curse 钳边返回实际增量（满层 add 返 0）；遥测 curses_taken / curses_purged。
- **max_hp 公式唯一真源**：`Player.compute_max_hp(char_pct, chip_sum, flat, curse_layers)
  = maxf((base×(1+char_pct)+chip_sum+flat)×(1−0.04n), 1.0)`（base 真源 cfg player_base_hp）；
  `CurseHandler.recompute_max_hp(heal_delta:=0.0)` 是运行期唯一写入口：heal_delta>0 →
  hp=minf(hp+Δ,new_max)（芯片回补口径）；否则比例缩放 hp×new/old。写回后广播。
- **EventBus 第 22 号信号** `curse_changed(count:int, max_hp:float)` + emit 包装；
  DataValidator.EVENT_NAMES 21 → **22** 双源镜像（pkg7:172 授权更新）。
- **双通道无敌**：Player.dash_invuln_left 与 invuln_left 并联递减；受击判定
  `invuln_left>0 OR dash_invuln_left>0`，互不覆盖（受击只写 invuln_left）。
- **接入点**：受伤 ×(1+0.08n)（deps.curse_handler 问询，null → 1.0）；金币掉率 chance 追加
  +0.15n（金币关 0.5 下限逻辑在其后）；chip equip max_hp 键 / 商店 maxhp（改
  max_hp_bonus_flat+=10 → recompute）全部经 recompute 通道（curse_handler null 兜底旧加法路径）；
  卡流 cursed 卡（_on_card_choice / _on_shop_purchase）→ add_curse(1)。
- respawn：max_hp = compute_max_hp(char_pct,0,0,0)、flat 池与冲刺计时清零。

## 11. 假设清单（方案未明说处的实现裁定 + 冲突处理，全部如实留痕）

- **R1 事件闸排除商店波（最小正确修复）**：冻结条件原文为
  `not _event_gapped and current_wave>=EVENT_START_WAVE and _extra_shop_pending==0`（在商店
  分支之后求值）。商店波首个 BUFFER tick 由商店分支 return，但同间隙第二次 tick
  （_shop_gapped 已置位）会落入事件闸——违反「非商店间隙」语义。实现显式追加
  `not _is_shop_wave(current_wave)` 条件。
- **R2 build_event 越界钳**：「越界钳」按 clampi(p,0,count−1) 实现（越界 → 末位事件）。
- **R3 神龛遗物 roll 用卡牌流**（card_generator.rng，同卡架遗物抽取口径）；rng 888 严格
  赌桌专用（pkg8 断言金币流 state 零消费佐证隔离纪律）。
- **R4 赌桌 B 语义**：「赌徒诅咒×2（curse+2）」按深渊层 +2 实现（括号内为准）；
  gambler（词条挂载）效果键保留未上表。
- **R5 悬空角色 id 的 apply_character**：冻结文本「player.apply_character(current_character)
  （null 跳过）」存在歧义（跳过调用 vs 跳过属性应用）。按「无条件调用 + 内部 null 清引用/
  跳过属性应用」实现——否则上局角色 char_pct/xp 残留进悬空 id 新局（respawn 公式语义破）。
  副作用：move_speed/pickup 残留前值（respawn 本就不重置它们，与 v0.7 语义一致）。
- **R6 冲刺方向归一化**：冻结公式 `_last_move_dir×(DASH_DISTANCE/DASH_TIME)×gd` 中
  _last_move_dir 若存原始拖动向量（每帧几 px）会令冲刺速度随输入长度漂移——按「最近非零
  方向」语义存**单位向量**。
- **R7 set_strip_available 追加带默认值展示参数**：`p_preview: String = ""`（冻结签名兼容，
  单参调用不受影响）——strip 按钮文案带预览词条名的数据通道。
- **R8 CardGenerator rng 不重播种维持现状**：v0.7.0 起卡牌流全局单流（seed 42，BOOT 定种），
  跨局不重播种（card_generator.owned_relics 由 _reset_run_state 清空但流状态延续）。
  事件系统神龛 roll 消费卡牌流属于该现状的自然延伸，不做重播种改造。
- **R9 契约 heal_delta 口径**：商店 maxhp 走 recompute()（默认 0 → 比例缩放）；
  芯片 max_hp 走 recompute(value)（>0 → 平加回补）——与「芯片回补口径」原文一致。
- **R10 事件闸 start_wave 连带**：黑市 pending 跳过 tick 不 return，直接 start_wave（闸与
  roll 均不消耗，下一间隙重新可触发）——「跳过不消耗」的直接语义。
