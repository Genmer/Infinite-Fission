# A8 · v0.9.0 设计留痕：波次赐福三选一 + 芯片槽位扩展 6 格

> 状态：已交付（与实现同步收尾）。上游：冻结方案（主控下发，架构已定照此落地）。
> 版本事实源 = `PROGRESS.md`；本文档为 v0.9.0 数值与裁定留痕（docs/analysis A 系列新增，入库）。

## 0. 范围与核心语义

- **波次赐福 = 三选一**：`wave_cleared`（w>=2）立即弹 `BlessingUI`（复用 SHOP 暂停态；复用
  PLAYING→SHOP 既有边，`TRANSITIONS` 零改动）。选项 = 可用池加权 roll 3 个**不同类**；
  **出牌时过滤**：slot1 仅 capacity<6 入池、slot2 仅 capacity<=4、heal 仅 hp<max_hp；
  gold/atk/rof/attach 恒入。可用池 <3 时 gold 补位（构造上不可达——gold 恒可用、池最小 4，
  防御行保留）。跳过按钮（无补偿，仅 DebugStats 遥测无信号）。
- **时序**：wave_cleared → BlessingUI 开 → 选/跳过 → 回 PLAYING → BUFFER 4s（磁吸+升级照旧）
  → buffer 尽商店/事件既有闸开门。一间隙最多赐福+商店/事件**两次暂停**。硬上限叠波直调
  `start_wave` 不派发 wave_cleared = 天然无赐福（pkg9 G6 固化）。
- **stat 三键 = Option A**：ChipHandler 持 `blessing_stats` 字典，`stat_bonus` **套装 ×1.10
  之后**加和（只加和不参与 ≥2 判定、不被放大）；不占 TraitStack、不可 strip；atk 并入后随
  芯片 ⑥b 段共享 `cap_chip_zone`。
- **槽位扩展**：`CHIP_SLOT_CAP=6`；`bonus_slots`（赐福位）+ `slot_capacity() =
  mini(unlocked_slots+bonus_slots, 6)`；w1/10/20 解锁链 clamp 1~3 不动；`reset_run` 归零
  `bonus_slots` + `blessing_stats`。

## §2 Option A 裁定（stat 三键寄存位置）

**裁定**：赐福 stat 三键（atk/rof/attach）寄存在 `ChipHandler.blessing_stats: Dictionary`
（键 = 芯片 stat 键，值 = 累加和），消费点在 `stat_bonus()` 的套装段**之后**：

```
stat_bonus(p_stat):
    total = Σ(主值 + 副词条同键)          # 既有
    if 主键计数 >= 2: total ×= 1.10       # 既有套装（判定只数芯片主属性）
    total += blessing_stats[p_stat]       # v0.9.0 赐福段：只加和
    return total
```

- **不参与 ≥2 判定**：赐福不会自己触发/凑成套装（主键计数只数 equipped 芯片）。
- **不被 ×1.10 放大**：加和在乘区之后（pkg9 G5 精确断言：双 atk 芯片 0.242 + 0.04 = 0.282）。
- **不可 strip**：商店「移除词条」只操作 TraitStack，blessing_stats 无 detacher。
- **atk 共享 cap_chip_zone**：atk_pct 经 weapon 面板进 ⑥b 芯片独立乘区段，整体钳制不变。
- **随局清零**：`ChipHandler.reset_run()` 归零 blessing_stats + bonus_slots。

被否决的备选（留痕）：写入 TraitStack（会被 strip/套装/面板缓存污染）、独立乘区（破坏
「不新增乘区名额」红线）。

## §3 时序图

```
wave_cleared(w)                          [WaveDirector tick 清空检测，PLAYING 态]
  ├─ relic_handler（黑市排程）           ┐ 连接序 = 派发序（boot 固定）
  ├─ shop_bridge（pending → queue_extra）│
  ├─ gold_rush（金币关波末奖励先入账）   │
  └─ blessing（w<2 return；否则开门）    ┘ ← v0.9.0 订阅固定在金币关之后

_open_blessing_flow(w)
  ├─ 四重守卫：非 PLAYING ∥ shop.is_open ∥ event.is_open ∥ blessing.is_open
  │    → _deferred_blessing = true（排空补开）
  └─ change_state(SHOP) → blessing_ui.open(roll_offers(w))

选牌 / 跳过
  ├─ choose(i)：守卫 SHOP+is_open+index 界内 → apply(kind, current_wave 兜 0)
  │    （slot 臂 got<=0 → false 不派发信号）
  ├─ skip：count_skip()（仅 DebugStats 遥测，无信号）
  └─ _close_blessing：close → PLAYING → _drain_overlays_after_resume()

_drain_overlays_after_resume（v0.9.0 冻结序）
  pending_level_ups（升级） → _deferred_blessing（赐福） → _deferred_shop_wave（商店）
  → _deferred_event（事件）——逐项消费命中即停

BUFFER 4s（赐福期间照常计时）：buffer 尽 shop/event 既有闸开门；赐福开着 → 商店请求
按既有非 PLAYING 门暂存 → 赐福毕排空补开（一间隙最多赐福+商店/事件两次暂停）

硬上限叠波：tick 内 start_wave(w+1) 直调，不派发 wave_cleared → 无赐福（pkg9 G6 固化）
```

`_reset_run_state` 追加：`blessing_ui.close()` / `_deferred_blessing=false` /
`blessing_handler.reset_run()`（rng 重播种 + 双遥测清零）。
