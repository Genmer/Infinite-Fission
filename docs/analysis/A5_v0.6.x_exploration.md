## 二、元素反应长期课题（参考原神，方向性草案）

> 定位：这是数个版本尺度的大课题。本文只锁方向与分期，不锁数值。

### 1. 现状盘点（真实根基，比"从零做"强得多）

| 已有 | 实现位置 | 对应原神概念 |
|---|---|---|
| 三元素 FIR/ICE/LTG + KIN 弃用槽 | GameConst.Element / elemental_state 4 槽 gauge | 七元素缩配 |
| 元素量槽 + λ 比例衰减 | F20 填充时间公式 | 附着元素量/衰减 |
| 三反应：碎裂(FIR+ICE=引爆剩余 DOT ×2.0) / 过载(FIR+LTG=120% ATK 爆炸) / 超导(ICE+LTG=全抗−30%/6s) | elemental_system.detect_reactions，优先级 碎裂>过载>超导，一帧一反应/敌 | 剧变反应族 |
| 感电连锁（3 目标/160px/35% 每跳/深度 2） | _shock_chain 独立 source_uid | 感电传导 |
| 反应独立结算通道（不掷暴击、快照系数） | resolve_reaction F21 | 反应伤害独立于直伤 |
| 反应强化乘区（×1.8 聚合） | register_reaction_mult | 元素精通雏形 |
| immune_mask 抗性/免疫 | enemy_data.resist + immune_mask | 元素免疫 |

### 2. 差距分析（相对原神参考系的核心缺失）

1. **无增幅轨**：现有三反应全是"剧变"型（固定系数/固定效果）。原神的深度一半来自**增幅反应**（蒸发 ×1.5 / 融化 ×2.0 直接乘算面板，吃构筑成长）——它让"前期剧变保底、后期增幅放大"成为可能，恰好对冲本项目"前期刮痧/后期溢出"的既有痛点。
2. **附着不可见**：玩家看不到敌人身上挂了什么元素、反应为什么触发（原神血条旁元素标记）。策略性存在但不可读。
3. **无元素精通面板**：×1.8 乘区是硬编码遗物词条，玩家无法构筑"精通流"。
4. **无破盾机制**：immune_mask 是全有全无，没有"元素盾=吸收对应元素伤害"的软克制层。
5. **反应 CD 不可见**（cd_rxn=2s 全局）。

### 3. 四维度设计方向

**设定层**
- 元素扩张路线：先深化 3 元素（3C2 组合已全覆盖）再加第 4 元素（候选：水——湿身状态=感电/冻结的前置放大器，与现有 ICE/LTG 联动最丰富）。不追七元素——本作弹幕密度下元素组合的辨识成本比原神高（无切人视角）。
- 附着强度分级（强/弱两档，对应原神 2U/1U）：驱动反应倍率分档，给"重元素武器 vs 快元素武器"差异化。

**数值层**
- 增幅/剧变双轨：新增 1~2 个增幅反应（如 FIR+KIN 直伤增幅 ×1.5？或改造碎裂为增幅）——剧变走现有 resolve_reaction 固定系数通道，增幅走乘区段（吃面板、占乘区名额、受钳 8.0 护栏），两轨不混。
- 元素精通独立乘区词条化：把 ×1.8 硬编码改为 ELEM 池可叠词条（精通+%），池内增员不动类别权重 10。
- 反应覆盖率预算：cd_rxn 分反应独立（碎裂 2s/过载 3s/超导 6s 之类），并给 UI 读数。

**表现层**
- 附着可视化：敌人头顶元素色环/角标（附着量→环进度，衰减可见）。
- 反应触发反馈：碎裂=冰晶爆裂粒子、过载=爆炸+顿帧（gamefeel 通道直接接事件）、超导=紫电丝+降抗图标。
- 弹体元素着色规范（element 键→弹体色相）。

**UI 层**
- 首次反应教学卡（一次性暂停提示）。
- 构筑面板元素覆盖页：本局各元素附着占比/反应触发统计。
- 结算屏反应伤害占比饼图（现有 total_damage 通道可扩展）。

### 4. 分期路线（每期独立可交付）

| 期 | 内容 | 性质 | 风险 |
|---|---|---|---|
| 一期（v0.6.x 末） | 附着可视化 + 反应触发粒子/顿帧 + 结算屏反应统计 | 纯表现+统计 | 零数值风险；性能=粒子池预算复核 |
| 二期（v0.7） | 增幅/剧变双轨 + 元素精通词条池 + 反应 CD 分立与 UI 读数 | 数值+少量管线 | 乘区名额与钳 8.0 护栏复核；A2 框架 F 系补公式 |
| 三期（v0.8+） | 第 4 元素（水）+ 元素盾破盾机制 + 环境物件（可附着场景物）+ 元素共鸣（N 把同元素武器 set bonus） | 系统级 | 敌表/波表/词诠三线联动；detect_reactions 复杂度预算 |

### 5. 护栏与红线（继承既有工程铁律）

- 全部新乘区受钳 8.0 / δ≤0.92 / ×500 保险钳既有红线约束，增幅轨不得绕过乘区段。
- 反应检测复杂度：帧末统一检测（E-07）保持，扩元素后按 hosts×反应对 预算，超线走降频。
- 词条扩池只增员不动类别权重（A4 口径）。
- 表现层改动须窗口模式真机实测（headless 测不到渲染卡顿——既有教训）。

### 6. 待用户拍板的决策点（动工前必须确认）

1. 第 4 元素选水还是别的（或不加）？
2. 增幅轨是否引入（改变直伤/反应的最优配比，影响全部 TTK 曲线）？
