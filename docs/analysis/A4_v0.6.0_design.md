## 3. 金币经济（掉率/面值真源）

掉率与面值**取敌 .tres `gold_drop` 与 A3 §6.5 原值**（已入表，本版零改动，仅接链路）：

| 敌 | chance | 面值 min~max | 来源 |
|---|---|---|---|
| E1_grunt 杂兵 | 6% | 8~12 | 〔A3 §6.5 原值〕 |
| E2_runner 疾冲者 | 8% | 10~15 | 〔A3 §6.5 原值〕 |
| E3_bastion 重甲 | 25% | 15~20 | 〔A3 §6.5 原值〕 |
| E4_volatile 爆虫 | 10% | 10（固定） | 〔A3 §6.5 原值〕 |
| E5_elite 精英 | 100% | 20~30 | 〔A3 §6.5 原值〕 |
| E6_boss1 / boss2 / boss3 | 100% | 100~140 / 120~160 / 100~160 | 〔A3 §6.5 原值〕 |

结算公式（GameLoop 掉落侧）：`chance = clamp(drop.chance + Σ add_gold_drop, 0, 1)` → RNG 判定 → `amount = round(randi_range(min,max) × (1 + Σ add_gold_value))`；空 dict / 负值 / 零面值三层 guard 全跳过。掉落为场上金币实体（磁吸吸收后入账），满池合并数值守恒。

## 6. TraitData.required_weapon 裁定（v0.6.0 新增字段）

- 字段：`required_weapon: StringName = &""`（空 = 无门槛，全部既有词条不受影响）。
- 语义：非空时，玩家未持有该 id 武器 → 卡牌候选池过滤（`_trait_candidates`）+ `apply_choice` 挂载前防御拒绝（push_warning 不生效）。
- 首个消费者：MEC_ORBIT_LINK（谐振轨道）→ `&"W8_orbit_field"`（A3 §4.4「仅装备 W8 时生效」的文字约束字段化落地）。

## 7. 裁定留痕清单（实现期逐条）

1. **商店期计时照常累计**：run_elapsed 在 HUD.tick（raw 通道）累计，SHOP 态 ⑦⑧ 照跑 → 与 LEVEL_UP 同口径，商店不产生时间停止观感。
2. **Boss3 charge / laser_sweep defer**：E6_boss3.boss 段的 charge/phase3/laser_sweep 键 v0.6.0 不消费（T7 只做 bullet_patterns fan/ring/spiral + summons），留待下版；DataValidator 仅做结构告警不剔除。
3. **敌弹不分账**：Boss 弹走既有弹池（soft 1500 / hard 2000），不入金币/独立配额；伤害只走 `panel_snapshot.base_atk → take_contact_damage` 单点（team=1 既有路径），禁入 DamagePipeline / settle_aoe——防双落血前科复发。
4. **Boss 弹幕节奏**：pattern/summons 计时器开场取 `interval_s × 0.5` 半冷却（防同帧齐射，与 RANGED fire_cd_left 同口径）；P2 判定统一 `boss_phase >= 2`（真源 `_check_boss_phase` HP<50%）。
5. **召唤上限**：`BOSS_SUMMON_ACTIVE_CAP = 12`（场上该 spawner 活跃数闸）；位置 = Boss 周围半径 90px 环形均分（无 RNG，确定性）；split 模式 `hp_override = max_hp × hp_ratio`。
6. **金币 RNG**：独立 `_gold_rng`（默认 seed 42，`set_gold_rng_seed` 可注），与卡牌 roll/出生点流互不串流。
7. **金币池容量**：pool_prewarm 增 "gold":96（架构 §5.1 表扩展，〔本版裁定〕）。
8. **SHOP 态帧序**：合并 LEVEL_UP/PAUSED 分支（仅 ⑦⑧ raw），frame_order 契约不变；tree.paused=true 冻结战斗。
9. **GameStatus.SHOP 枚举**：尾部追加值 6，零重编号；TRANSITIONS：PLAYING→SHOP 增边、SHOP→[PLAYING, GAME_OVER]。
10. **HUD 布局**：720×1280 全量坐标表见 T2（layout_rects 断言矩形两两不相交）；金币标签色 Color(1.0,0.83,0.25)。
11. **经验碎片让色**：SHARD_COLOR 改青蓝 Color(0.35,0.8,1.0)（金色让位金币）；CRIT 跳字加描边（可读性）。

## 9. 实现期补充留痕（T1~T7 落地口径，pkg6 断言锁定）

1. **layout_rects 行高口径**：标签占位矩形行高 = font_size + 8（设计口径）。headless fallback 字体
   行高膨胀 ~3×（get_height 48@size16），与 §7 坐标表前提（真实字体 ~1.4×）不符——布局契约按
   设计口径声明，宽度取实测最小宽。
2. **黑市桥接为即时消费**：`_on_wave_cleared_shop_bridge` 每次 relic 排程（pending+1）即消费并转
   `queue_extra_shop()`，pending 回落 0——pkg5 原「占位计数 2」断言随此契约更新（单申请挂
   `_extra_shop_pending`，单间隙单店闸去重）；`WaveDirector.reset_extra_shop()` 于重开时清申请位
   （与 relic reset 同口径，不跨局）。
3. **split 召唤 hp_override 单点**：仅 EnemySpawner.tick 出队段消费（>0 → max_hp=hp=maxf(v,1)），
   Boss 侧入队时折算 `max_hp × hp_ratio`；spawner 注入 `summon_spawner=self` 于出队段（与
   projectile_pool/enemy_grid 同段）。
4. **Boss 弹幕池满降级**：`acquire()` 返回 null → 跳过该发（不阻塞不崩溃，池语义一致）；
   弹速 P2 乘区读 `speed_mult_phase2`（Boss2 ×1.4 → 420px/s）。
5. **商店 roll 确定性**：卡架与武器架 roll 均走 CardGenerator.rng（seed 42 流），同种子货架可复现；
   `shop_exclude_weapon` 跳过 WEAPON 类别时消耗一次类别 roll（attempt 递减语义）。
6. **金币 roll 独立流**：`_gold_rng`（seed 42）只承担 chance 判定与面值 roll，与卡牌/出生点流零串扰；
   `set_gold_rng_seed()` 为测试/遥测注入口。
